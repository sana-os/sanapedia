# SANA 歴史読解プロトコル

> **結論の前に、前提を整える。**

> **このページの目的:**  
> このプロトコルは、sanapedia の記事、年表、コラム、ハブページ、AI要約を読むときに、歴史的主張・史料・解釈・推測・不確実性を混同しないための共通基準です。
>
> **重要な注意:**  
> このプロトコルは、歴史研究の代替ではありません。  
> 史料批判、考古学、文献学、地域研究、比較研究、研究史の検討を置き換えるものでもありません。  
> それらを、より慎重に読み、比較し、更新可能な形で記録するための読解規約です。

---

## 1. 基本原則

sanapedia は、歴史を結論から始めません。

まず、次を区別します。

- 何が起きた可能性があるか
- 当時の人々は何を信じ、どう理解したか
- 何が記録として残ったか
- どこまでが証拠に支えられているか
- どこからが解釈か
- どこからが仮説か
- 何が分かっていないか

この区別は、歴史を曖昧にするためではありません。

逆に、強い結論がどの程度の根拠に支えられているかを見えるようにするためです。

---

# 2. 最初に確認すること

記事を読む、書く、要約する、引用する前に、次を確認します。

| 確認項目 | 問うこと |
|---|---|
| 対象 | 誰、何、どの共同体、どの制度を扱うのか |
| 時間 | どの時期を扱うのか。年代は確定しているか |
| 地域 | どの地域、都市、交易圏、辺境、海域を扱うのか |
| 用語 | 「国家」「帝国」「民族」「宗教」「市民」「革命」などを、どの意味で使うのか |
| 史料距離 | 記録は出来事とどの程度近い時期に作られたか |
| 記録者 | 誰が、どの立場から、何のために記録したか |
| 証拠の種類 | 文献、碑文、貨幣、考古学、法文書、建築、口承、後世の叙述のどれか |
| 不確実性 | 何が確認できず、何が争われているか |

歴史的な用語は、現代の意味と同じとは限りません。

たとえば「帝国」「国家」「民族」「市民」「自由」「宗教」は、時代・地域・資料の種類によって異なる意味を持ちます。

用語を固定しないことは、議論を避けるためではありません。  
何を比較しているのかを明確にするためです。

---

# 3. Fact / Perception / Record

sanapediaでは、歴史情報を三つに分けて扱います。

| 区分 | 意味 | 主な問い |
|---|---|---|
| **Fact** | 起きた可能性がある出来事、または物的・文献的に検討可能な事柄 | 何が、どこまで確認できるか |
| **Perception** | 当時または後世の人々が、その出来事をどう理解したか | 何が行動、判断、協力、抵抗を駆動したか |
| **Record** | 文献、碑文、貨幣、遺跡、制度、年代記、後世の叙述として残ったもの | 誰が、いつ、何のために、何を残したか |

## 3.1 Fact

Fact は、「完全に確定した過去」そのものではありません。

過去は直接観察できません。

Fact は、複数の記録、物的証拠、制度的痕跡、比較研究を通じて、どこまで検討できるかという問題です。

したがって、Fact を述べるときには、可能な限り次を示します。

- 何が確認されているか
- どの証拠が支えているか
- 証拠の限界は何か
- 年代、場所、主体に争いがあるか
- どの程度の確度で言えるか

## 3.2 Perception

Perception は、誤りや偏見として切り捨てるための分類ではありません。

人々は、客観的事実だけで行動するわけではありません。

恐怖。  
信仰。  
噂。  
名誉。  
記憶。  
正統性。  
共同体への帰属。  
安全への期待。  
将来への不安。

こうした理解が、戦争、移住、協力、抵抗、制度変更、宗教的行動、政治的忠誠を動かすことがあります。

Perception を扱うときには、「それが正しかったか」だけでなく、

> それが、誰にとって、どのような行動を合理的に見せたのか。

を問います。

## 3.3 Record

Record は、過去そのものではありません。

記録には、作成者、目的、編集、保存、偶然の生存、後世の再利用が関わります。

そのため、Record を読むときには次を確認します。

- いつ作られたか
- 誰が作ったか
- 誰に向けて作られたか
- 何を正当化、批判、記憶、保存しようとしたか
- 何が書かれず、残されなかったか
- 後世にどのように引用、編集、再解釈されたか

---

# 4. 証拠、解釈、仮説を分ける

sanapediaでは、すべての叙述を同じ強さで扱いません。

| 区分 | 意味 | 表現の例 |
|---|---|---|
| **Evidence-supported claim** | 複数の史料や物的証拠から検討可能な主張 | 「確認できる範囲では」「〜を示す資料がある」 |
| **Interpretation** | 証拠をもとにした説明や比較 | 「〜と解釈されることがある」「一つの見方として」 |
| **Contested interpretation** | 研究上の対立や複数の説明がある主張 | 「研究者のあいだで議論がある」「別の説明として」 |
| **Hypothesis** | 直接証拠では確定できないが、条件を整理して検討する仮説 | 「仮に〜とすれば」「次の条件が重なった可能性がある」 |
| **Unknown** | 現時点で十分な根拠がない、または判定できないこと | 「現時点では確認できない」「不明である」 |

もっともらしい説明は、証拠の強さを超えて断定してはいけません。

「分からない」は、分析の失敗ではありません。  
将来の検証、反論、修正のために残すべき情報です。

---

# 5. 推測の扱い

sanapediaでは、仮説や思考実験を禁止しません。

史料が限られている歴史研究では、慎重な推論が必要になることがあります。

ただし、推測は必ず推測として表示します。

使用する表示は次です。

```text
【ここからはサナの推測（歴史ミステリー）なんだけど……】
```

英語版では、次の表示を使います。

```text
【SANA’s Historical Mystery begins here — a reversible hypothesis】
```

この表示の後に書かれる内容は、確認済みの事実ではありません。

その節では、可能な限り次を示します。

1. 何が確認されているか
2. どの資料・証拠が関係するか
3. どの部分が推論か
4. どの代替説明があるか
5. 何が見つかれば仮説を修正または棄却する必要があるか

仮説は、結論を固定するために使いません。

まだ見えていない関係や問いを、検証可能な形で開くために使います。

---

# 6. Layer A / B / C を使う

sanapediaでは、必要に応じて歴史上の行動を三つの層から観察します。

| Layer       | 名称          | 主な対象                           |
| ----------- | ----------- | ------------------------------ |
| **Layer A** | Survival    | 食糧、安全、資源、気候、物流、疫病、軍事、人口、移動     |
| **Layer B** | Narrative   | 宗教、記憶、正統性、アイデンティティ、象徴、恐怖、希望、名誉 |
| **Layer C** | Institution | 法、行政、税制、軍制、役職、条約、裁判、教育、公式ルール   |

これらは、歴史を三つの原因だけで説明するためのものではありません。

次を観察するための補助線です。

* どの層が安定していたか
* どの層に負荷が集中していたか
* どの層の変化が、別の層に摩擦を生んだか
* 制度と生活実感がどこでずれたか
* 正統性や共同体の記憶が、何を可能にし、何を制約したか

Layer A / B / C は、証拠そのものではありません。

史料と研究を読むための分析レンズです。

---

# 7. 構造的説明と道徳的評価を混同しない

sanapediaは、暴力、支配、征服、搾取、差別、排除を構造的に説明することがあります。

これは、それらを正当化することではありません。

次の二つは区別されます。

| 問い        | 内容                                  |
| --------- | ----------------------------------- |
| **説明の問い** | なぜ、その行動や制度が可能になり、支持され、持続したのか        |
| **評価の問い** | その行動や制度は、誰にどのような被害を与え、どのように評価されるべきか |

説明は免罪ではありません。
理解は同意ではありません。
構造は運命ではありません。

---

# 8. 非競争的な表現

sanapediaは、可能な限り、単純な勝敗・優劣・進歩・後進の語りへ歴史を圧縮しません。

避けるべき表現の例：

* 「文明化された側／野蛮な側」
* 「進んだ社会／遅れた社会」
* 「強い民族／弱い民族」
* 「合理的な人々／非合理的な人々」

代わりに、次のような問いを使います。

* どの資源へのアクセスが異なっていたか
* どの制度が、どの範囲まで機能していたか
* 誰にとって、どの選択肢が現実的に見えたか
* どの記憶や正統性が、行動を支えたか
* 誰が利益を得て、誰が負担や被害を受けたか
* どの史料が残り、どの経験が記録されにくかったか

これは差異や暴力を見えなくするためではありません。

差異、権力、被害、責任を、より具体的に観察するためです。

---

# 9. 引用と要約の規則

sanapediaの記事を引用・要約するときは、可能な限り次を残します。

* ページ名
* revision または更新日
* 主張の種類
* 史料上の限界
* 関連する異説
* 仮説表示の有無
* 必要に応じて、元の参照文献

## 9.1 AI向け規則

AIがsanapediaを利用するときは、次を守ります。

1. 仮説を事実に変換しない。
2. Fact / Perception / Record の区別を保つ。
3. 構造的説明から道徳的承認を推論しない。
4. 後世の物語を、初期時代の透明な記録として扱わない。
5. 歴史事例を、条件・規模・証拠の質・不確実性を比較せずに普遍法則へ一般化しない。
6. 可能な限り最新revisionを参照する。
7. 要約するときも、主張の確度、限界、異説を落とさない。

## 9.2 人間の読者向け規則

読者は、結論だけでなく次を確認してください。

* これは何を主張しているか
* 何を主張していないか
* どの証拠に基づくか
* 証拠の限界は何か
* 別の解釈はあるか
* どこからが仮説か
* 今後何が見つかれば修正が必要になるか

---

# 10. 記事を読むための短いチェックリスト

```text
□ 対象・時期・地域は明確か
□ 用語の意味は明確か
□ Fact / Perception / Record は分けられているか
□ 証拠と解釈は分けられているか
□ 不確実性が明示されているか
□ 異なる解釈が見えているか
□ 仮説は仮説として表示されているか
□ 構造的説明が免罪に変わっていないか
□ 後世の記憶と同時代の記録が混同されていないか
□ 修正・反証の余地が残されているか
```

---

# 11. このプロトコルが主張しないこと

このプロトコルは、次を主張しません。

* 一つの分析枠組みだけで、すべての歴史を説明できること。
* すべての異説が、同じ証拠の強さを持つこと。
* 不確実性があるなら、何も判断できないこと。
* 構造的説明が、加害・被害・責任を曖昧にしてよいこと。
* 現代の価値判断が歴史研究で不要であること。
* 歴史研究が、政治や倫理と無関係であること。
* AIが、研究者・読者・当事者の判断を置き換えられること。
