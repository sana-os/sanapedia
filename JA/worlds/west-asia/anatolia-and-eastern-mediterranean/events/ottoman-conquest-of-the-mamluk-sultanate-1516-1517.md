# オスマンによるマムルーク朝征服、1516–1517年

> **研究状態:** Provisional  
> **中心問題:** 1516–1517年のオスマン＝マムルーク戦争は、なぜ二つのスンナ派イスラーム政権の会戦を超えて、シリア・エジプト・ヒジャーズ・紅海・巡礼・都市・軍事者・収益を再接続する長期的な統治転換になったのか。  
>
> **注意:** このページは征服を「マムルーク朝が弱かったので倒れた」という一行で説明しない。また、オスマンの勝利を、地域社会にとって自動的な安定や繁栄だったとも扱わない。

---

# Human Overview

1516年から1517年にかけて、セリム1世の軍はマムルーク朝を破り、シリアとエジプトをオスマン支配圏へ組み込んだ。

主要な軍事的節目は、

- 1516年8月24日、マルジュ・ダービクの戦い
- 1517年1月22日、リダニーヤの戦い
- 1517年初頭、カイロの制圧
- 1517年春、トゥーマーン・バーイ2世の捕縛・処刑
- 1517年夏、ヒジャーズの服属と聖地保護の再配置

である。[^tdv-selim][^holt-occupation]

しかし、これは単純な「古い国家が新しい国家へ置き換わった」出来事ではない。

マムルーク朝は、カイロとダマスクスを中心に、シリア、エジプト、ヒジャーズ、紅海航路、巡礼、地中海・インド洋交易、軍事者、都市学者、農村収益をつなぐ長期的な政治体だった。

オスマン側が勝利した後に直面したのは、領土を地図に加えることではなく、

- カイロとダマスクスの都市秩序
- 旧マムルーク軍事者と行政実務者
- 穀物・税・農村収益
- 巡礼路と聖地への物資
- 紅海とポルトガル勢力を含む海上圧力
- 旧来の有力者、学者、商人、職人
- シリアとエジプトをイスタンブルの命令体系へどう接続するか

という問題だった。[^holt-occupation][^new-cambridge-egypt-syria]

マルジュ・ダービクでは、マムルーク朝君主カンスフ・ガウリーが死亡し、シリアの政治秩序が急速に変化した。

ただし、彼の死を一人の将軍の裏切りや、火器への無理解だけで説明することはできない。

軍事配置、指揮、補給、部隊間の関係、シリア諸都市の選択、長期的なオスマン＝マムルーク競争が重なっていた。[^holt-occupation]

1517年、セリム1世はシナイを越えてエジプトへ入り、リダニーヤでトゥーマーン・バーイ2世の軍を破った。

カイロでは戦闘と抵抗が続き、征服は一度の入城で完了しなかった。

トゥーマーン・バーイは抵抗を継続した後に捕らえられ、処刑された。[^tdv-selim][^holt-occupation]

征服後、メディナとメッカはセリムに服属し、オスマン王朝は聖地保護者としての位置を強めた。

ただし、このことを「1517年にカリフ位が一回の儀式で移譲された」とする後世の単純な物語と同一視しない。[^new-cambridge-egypt-syria]

このページでは1516–1517年を、

> 二つの軍隊の勝敗ではなく、シリア・エジプト・ヒジャーズ・紅海・巡礼・都市・軍事者・収益が、別の帝国の制度へ接続され直す過程

として扱う。

# Why This Event Matters

この事件は、次の問いを考えるための核になる。

- なぜ二つのスンナ派政権は、1516年に全面戦争へ進んだのか。
- なぜ火器は重要でも、戦争の結果を単独で説明できないのか。
- シリアとエジプトの征服は、なぜ会戦後の都市・収益・軍事者・港・巡礼の運用問題になったのか。
- カイロとダマスクスは、イスタンブルから遠い帝国都市としてどのような位置に変わったのか。
- 旧マムルーク軍事者・学者・商人・職人を、排除・利用・再配置のどの組み合わせで扱ったのか。
- ヒジャーズと紅海への接続は、宗教的威信だけでなく、物流・巡礼・海上安全・財政とどう関係したのか。
- 征服は地域社会の税、土地、軍役、移動、都市市場にどのような不確実性を生んだのか。
- 「カリフ位の移譲」物語は、何を後から単純化したのか。

# Source Problem

## 「オスマン対マムルーク」は宗教戦争ではない

1516–1517年の戦争は、しばしばオスマンとマムルークの「イスラーム世界の覇権争い」と説明される。

この説明は一部正しい。

両政権はスンナ派の保護者としての正統性を主張し、サファヴィー国家の台頭、地中海・紅海・インド洋におけるポルトガルの圧力、巡礼路と聖地への責任を意識していた。[^holt-occupation][^new-cambridge-egypt-syria]

しかし、それだけでは足りない。

同時に重要だったのは、

- ドゥルカディルをめぐる競争
- シリア北部とアナトリア南東部の境界
- 1485–1491年の先行する戦争
- マムルーク軍事体制とオスマン中央軍の異なる編制
- 絹・香辛料・穀物・港湾・関税
- カイロとダマスクスの都市政治
- 地方有力者と軍事者の立場
- サファヴィー朝とポルトガルを含む広域環境

である。

## 「マムルーク朝は弱かった」だけでは足りない

マムルーク朝末期には、軍事・財政・政治上の困難があった。

しかし、これを「衰退したため当然に敗北した」と扱うことはできない。

マムルーク政権は、長年にわたってシリア、エジプト、ヒジャーズ、紅海を結ぶ政治・軍事・都市・宗教の仕組みを維持していた。

1516–1517年の敗北は、

- 軍事技術
- 補給
- 指揮
- 部隊構成
- シリア諸都市の対応
- オスマンの長距離動員
- マムルーク側の防衛戦略
- 地方有力者の選択
- 戦後の抵抗と処罰

が重なった結果として読む必要がある。

# Historical Context

## Before: 長期競争と複数の境界

オスマンとマムルーク朝は、1516年以前にも競争していた。

1485–1491年には戦争があり、ドゥルカディル、カラマン、チュクロヴァ、シリア北部の境界をめぐる緊張が続いていた。

1514年のチャルディラーン後、セリム1世はサファヴィー国家を消滅させることはできなかった。

東方国境を抱えたまま、彼は南方でマムルーク朝と向き合うことになった。

そのため1516年の戦争は、単に「次の征服」ではない。

> サファヴィー、ドゥルカディル、シリア、エジプト、紅海、巡礼、交易を同時に扱うための境界再編

だった。

## During: シリアからシナイへ

マルジュ・ダービク後、オスマン軍はシリアへ入り、アレッポ、ダマスクス、ガザを経てエジプトへ向かった。

この移動には、

- 兵士
- 馬
- 水
- 食糧
- 砲
- 荷車
- 道路
- 砂漠越え
- 都市の市場
- 地方有力者
- 情報と使節
- 旧支配層の選択

が必要だった。

リダニーヤ後のカイロでは、戦闘が終わったとしても統治は始まらない。

都市の住民、軍事者、学者、商人、職人、農村収益、港、河川、巡礼に関わる多くの回路を、再び動かす必要があった。

## After: 征服ではなく統合の困難

征服後、カイロとダマスクスはオスマンの重要な州都になった。

しかし、イスタンブルから見れば両都市は遠く、命令・報告・人員・税・軍事・巡礼の接続には時間と摩擦があった。[^new-cambridge-egypt-syria]

征服後に問われたのは、

- 誰が地方行政を担うか
- 旧マムルーク軍事者をどう扱うか
- 都市の税と市場をどう維持するか
- 巡礼を誰が守り、誰が物資を運ぶか
- 紅海の海上圧力にどう対応するか
- カイロ、ダマスクス、アレッポ、メッカ、メディナをどの制度で結ぶか

だった。

この問題は1524年のハイン・アフメト・パシャ反乱、1538年の紅海・インド洋政策、後のエジプト財政政策へ続く。

# Layer A — 生存・物質的安定性層

## 軍事征服を可能にした物資

1516–1517年の戦争では、戦闘前後に次のものが必要だった。

- 兵士と馬
- 食糧、水、飼料
- 砲、火器、弾薬、荷車
- シリアの道路と都市市場
- シナイ越えの水・輸送・情報
- カイロの都市空間とナイル周辺の補給
- 軍事給与と戦利品の配分
- 港、紅海、地中海、河川輸送
- 巡礼隊への食糧・安全・管理
- 農村収益と穀物の流通

会戦の勝利は、このような物質的接続を維持できたかどうかと切り離せない。

# Layer B — 意味・認識層

## 聖地、スンナ派的正統性、都市の記憶

征服は軍事だけの問題ではなかった。

それは、

- 誰が巡礼を守るか
- 誰がメッカとメディナに物資を送るか
- 誰がカイロとダマスクスの都市秩序を保証するか
- 誰がスンナ派世界の保護者として見られるか
- 旧マムルーク軍事者の名誉と生存をどう扱うか
- オスマン軍の到来を都市住民が脅威・機会・負担のどれとして経験するか

という意味の競争でもあった。

| 主体 | 主な意味の問題 |
|---|---|
| セリム1世 | 王朝威信、征服の正当化、聖地保護、軍事者の統制 |
| マムルーク君主・軍事者 | 王朝の持続、軍事名誉、カイロとシリアの防衛 |
| シリアの都市住民 | 戦争回避、都市安全、税、商業、宗教施設 |
| カイロ住民 | 市街戦、略奪、軍隊、物価、生活、家族、財産 |
| 学者・裁判官 | 法、任官、ワクフ、宗教的正統性、都市秩序 |
| 商人・職人 | 港、関税、香辛料、絹、輸送、移送、需要 |
| ヒジャーズの有力者 | 巡礼、聖地、物資、軍事保護、カイロとの関係 |
| 後世の記録者 | 征服、カリフ位、聖地、スルタンの正統性という物語 |

## 「カリフ位の移譲」をどう扱うか

征服後、オスマン王朝はカイロ、ダマスクス、メッカ、メディナとの関係を通じ、イスラーム世界における位置を強めた。

しかし、

> 1517年に最後のアッバース朝カリフが、儀式で全ての権利をセリム1世へ譲渡した。

という定型的な物語は、このページでは確定事実として扱わない。

より確実に言えるのは、

- オスマン王朝が旧マムルーク領と聖地への責任を引き受けたこと
- 聖地保護とスンナ派的正統性の主張が強まったこと
- 後世にカリフ位をめぐる記憶が、征服の意味を単純化して再構成したこと

である。

# Layer C — 制度・運用層

## 征服後に必要な制度

シリアとエジプトを「征服」した後、オスマン政府は、次の制度を再接続する必要があった。

| 制度・運用 | 何が問われたか |
|---|---|
| 州行政 | 誰がアレッポ、ダマスクス、カイロなどで命令を執行するか |
| 旧軍事者の処遇 | 排除、再任、監視、給与、地方秩序をどう組み合わせるか |
| 税・土地・農村収益 | 既存の収益構造をどこまで維持・変更・記録するか |
| 裁判と学者 | 法、任官、ワクフ、都市秩序をどう扱うか |
| 都市市場 | 食糧、価格、通商、関税、職人、港をどう維持するか |
| 巡礼 | カイロ・ダマスクス・ヒジャーズを、人・物資・道路・儀礼でどう結ぶか |
| 紅海 | スエズ、ジェッダ、アデン、ポルトガル圧力への対応をどう設計するか |
| 首都との通信 | 遠隔の州都を、使節、書状、財務、人事でどう接続するか |

## 旧制度の消滅ではなく再配置

1517年は、マムルーク朝の君主政が終わった年である。

しかし、それは旧来の人々、知識、都市制度、農村収益、軍事経験が消えた年ではない。

むしろ、征服後には、

- 旧軍事者をどこまで残すか
- どの都市有力者を任用するか
- 学者と裁判制度をどう扱うか
- 既存のワクフをどう維持・監査するか
- 新しいオスマン官僚・軍事者をどこに置くか

という再配置が必要になった。

このため、征服は「古い体制の完全な消滅」ではなく、

> 古い回路を、部分的に残し、部分的に切り、部分的に新しい帝国の制度へ接続し直す過程

として理解する必要がある。

> オスマン軍がマムルーク軍に勝ったか。

だけではない。

むしろ、

> シリア、エジプト、ヒジャーズ、紅海、都市、軍事者、巡礼、収益を、誰がどの制度で新しい帝国の運用へ接続できるか。

である。

## GMM上の読み方

1516–1517年の征服は、完成された制度が新領土へそのまま移植された出来事ではない。

より慎重には、

> オスマン政権が、マムルーク朝の都市・軍事・農村・巡礼・海上の既存回路を、戦争と処罰を伴いながら、部分的に吸収し、部分的に再設計しようとした過程

として読むことができる。

# Competing Interpretations

## Interpretation A: オスマンの軍事技術と中央軍の勝利

この解釈は、砲、銃兵、軍事編制、補給、長距離動員を重視する。

重要だが、これだけではシリア・エジプトの都市政治、旧軍事者、戦後抵抗、行政移行を説明できない。

## Interpretation B: スンナ派世界の覇権再編

この解釈は、カイロ、ダマスクス、ヒジャーズ、聖地、サファヴィー朝との競争を重視する。

重要だが、「カリフ位が一度に移譲された」という単純な物語にしない。

## Interpretation C: 都市・巡礼・紅海の統治接続

この解釈は、征服の重要性を、カイロ、ダマスクス、メッカ、メディナ、紅海、巡礼路、穀物、港、都市行政の再配置に見る。

## Interpretation D: 旧マムルーク回路の選択的な再利用

この解釈は、征服後に旧マムルーク軍事者・学者・都市有力者・制度が、完全に消滅したのではなく、選択的に再配置・監視・利用されたことを重視する。

## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

1516–1517年の最大の問題は、

> セリム1世がマムルーク軍に勝てるか。

だけではなかったのかもしれない。

むしろ、

- シリアを通過し、シナイを越える軍を、食糧、水、馬、砲、給与、都市市場でどう維持するか
- カイロを取った後、旧軍事者、都市住民、商人、学者、農村収益をどう扱うか
- メッカとメディナを、単なる称号ではなく、巡礼・物資・道路・港・安全の問題としてどう支えるか
- 紅海の港と海路を、ポルトガル圧力やインド洋交易の変化のなかでどう扱うか
- マムルーク朝の既存制度を全て壊さず、しかし新しい王朝の命令体系へどうつなぐか
- 征服の宗教的正統化が、都市・地方・宗教集団の間にどのような新しい距離をつくるか

が同時に問われていた可能性がある。

この見方では、1516–1517年は単なる「帝国の拡大」ではない。

> カイロ、ダマスクス、ヒジャーズ、紅海、巡礼、旧軍事者、都市収益を、遠隔のイスタンブル中心政権へ接続し直そうとする、巨大な統治の移行

として見えてくる。

ただし、この構造的説明は、戦争、処刑、略奪、財産取得、移送、軍事徴発、地域社会への負担を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- マムルーク朝が「弱かったから当然に滅んだ」と主張しない。
- マルジュ・ダービクとリダニーヤを、火器だけで説明しない。
- カンスフ・ガウリーの死を単純な裏切り物語として固定しない。
- シリア・エジプトの都市住民が一様にオスマン支配を歓迎、または拒絶したと主張しない。
- 1517年にカリフ位が一度の儀式で完全移譲されたと主張しない。
- ヒジャーズの服属を、巡礼・物流・港・地域政治から切り離した宗教的象徴だけとして扱わない。
- 旧マムルーク軍事者・学者・商人・職人が一律に排除された、または一律に保護されたと主張しない。
- カイロとダマスクスが直ちにイスタンブルと同じ制度で運用されたと主張しない。
- 征服後の移送・財貨取得を、すべて自発的、またはすべて同じ種類の強制と一括りにしない。
- 構造的説明を、戦争、略奪、処刑、徴発、拘束、移送、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
