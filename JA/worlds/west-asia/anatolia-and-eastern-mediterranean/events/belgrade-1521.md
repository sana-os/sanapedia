# ベオグラード、1521年

> **研究状態:** Provisional  
> **中心問題:** 1521年のベオグラード征服は、なぜ一つの要塞の陥落を超えて、ドナウ・サヴァ両河川、周辺堡塁、舟橋、砲、補給、ハンガリー王権、住民移動、都市市場を再接続する中欧の統治転換になったのか。  
>
> **注意:** このページは、ベオグラードを「ヨーロッパへの門」という比喩だけで扱わない。城壁、河川、港、船、周辺集落、食糧、軍事者、住民、道路、都市収益が、実際にどう接続され直したかを扱う。

# Human Overview

1521年夏、スレイマン1世の軍はハンガリー王国が支配していたベオグラードを包囲し、8月末に要塞を確保した。

ベオグラードはドナウ川とサヴァ川の合流点に位置し、中央ヨーロッパ、バルカン、黒海、エーゲ海を結ぶ自然な交通回路の近くにあった。

この地理は、都市を単なる城壁ではなく、

- 河川交通
- 舟橋
- 船と砲
- 周辺堡塁
- 兵糧と飼料
- ドナウ沿いの市場
- ハンガリー南部とセルビア北部の軍事線
- 中欧への進軍路

を結ぶ結節点にしていた。[^tdv-belgrade]

オスマン側は、ベオグラードを直接包囲する前に、サヴァ川沿いのボーグルデレンを1521年7月7日に確保した。

この作戦により、ベオグラード西方の河川線と周辺堡塁への圧力が高まり、包囲の条件が変わった。[^tdv-bogurdelen]

ベオグラード自体は、すでに1440年にムラト2世、1456年にメフメト2世が攻略を試みたが、いずれも陥落させられなかった。

1521年の作戦は、過去の失敗を単に繰り返したものではなく、河川、周辺拠点、砲、軍事輸送、ハンガリー側の政治的制約を異なる形で組み合わせた包囲だった。[^tdv-belgrade]

ピリ・メフメト・パシャは、ベオグラードを「ヨーロッパの鍵」として優先すべきだとスレイマンに繰り返し進言し、包囲にも参加したと記録される。

パルガル・イブラヒム・パシャも、この遠征期にはスレイマンの内廷近臣として軍事行動に関わっていた。[^tdv-piri][^tdv-ibrahim]

征服後、ベオグラードはセメンディレ県の中心となった。

要塞は補強され、守備隊が置かれ、ドナウ艦隊の支援を受ける軍事拠点へ変化した。

同時に、住民の一部はイスタンブルへ移され、後に「ベオグラードの森」や「ベオグラード門」と結びつく記憶を残した。[^tdv-belgrade]

この移動を、征服の周辺的な出来事として扱うことはできない。

それは、都市の人口、労働、宗教共同体、住居、市場、要塞守備、帝都との関係を変える統治行為だった。

このページではベオグラード1521年を、

> ドナウとサヴァの合流点をめぐる要塞戦であると同時に、河川・兵站・人口・市場・城砦・中欧進出の回路を再編した事件

として扱う。

# Why This Event Matters

- 要塞は、なぜ城壁だけでなく、河川・港・砲・舟橋・市場・道路・周辺堡塁の組み合わせなのか。
- ドナウ川とサヴァ川の合流点は、なぜ軍事だけでなく、商業・人口・行政にとっても重要だったのか。
- 過去に失敗した包囲が、1521年にはなぜ異なる条件で成功したのか。
- ボーグルデレンなど周辺拠点の確保は、ベオグラード包囲にどのような変化をもたらしたのか。
- 住民移送は、都市の軍事拠点化と帝都の人口政策にどう関わったのか。
- 要塞守備にキリスト教徒出身のマルトロスなどが置かれたことは、国境統治の複合性を何に示すのか。

- 都市の再建・モスク・市場・駐屯地の形成は、誰にとって保護、機会、負担、移動、喪失だったのか。

# Source Problem

## 「ヨーロッパへの門」という比喩の限界

ベオグラードは、しばしば「ヨーロッパへの門」または「中欧の鍵」と呼ばれる。

この比喩は、ドナウ・サヴァの合流点にある要塞の戦略的意味を示す。

しかし、比喩だけでは見えなくなるものがある。

- 河川の流れと水位
- 船の移動
- 砲と弾薬
- 木材と舟橋
- 周辺堡塁
- 村・町・市場
- 守備隊の給与と食糧
- 住民の移動
- 宗教共同体
- 実際の道路と渡河地点

このページでは、比喩を残しつつ、それを支えた物質的・制度的条件を優先する。

## 征服後の住民移動

オスマン側資料は、ベオグラード住民の一部がイスタンブルへ移送され、後にベオグラードの森やベオグラード門と呼ばれる場所に関わったと伝える。[^tdv-belgrade]

ただし、

- 移送人数
- 残留者と移送者の比率
- 自発性と強制の程度
- 移送後の職業・住居・宗教生活
- 既存共同体への影響

は、一律には確定できない。

このため、人口移動を「定住政策」とだけ呼んで終えることは避ける。

# Historical Context

## Before: 1440年・1456年の失敗から1521年へ

ベオグラードは、15世紀に複数回の包囲を耐えた。

1440年のムラト2世による包囲は、抵抗と軍内の疾病のため解除された。

1456年のメフメト2世による包囲も成功しなかった。[^tdv-belgrade]

このため、1521年の征服を「必然的な再挑戦」として扱うべきではない。

1521年に変わっていたのは、

- オスマン軍の動員能力
- 河川と周辺堡塁への接近
- ハンガリー王国の政治・軍事環境
- スレイマン1世の新政権の優先順位
- ピリ・メフメト・パシャらが提示した戦略
- ドナウ線を前方基地として使う構想

だった。

## During: 河川、周辺要塞、砲、兵站

ベオグラード包囲は、城壁への砲撃だけではない。

包囲には、

- サヴァ川とドナウ川の水上移動
- 舟橋
- 船と河川艦隊
- 砲・弾薬・砲兵
- 周辺堡塁
- 木材
- 兵糧
- 馬と飼料
- 守備側の救援可能性
- 軍の宿営と疾病
- 周辺村落・市場への負荷

が関わった。

ボーグルデレンの確保は、こうした包囲の外側の条件を変える行動だった。

## After: 城塞・人口・市場を再配置する

征服後、ベオグラードは単にオスマン軍の旗が掲げられた都市ではない。

それは、

- セメンディレ県の中心
- ドナウ河川線の守備拠点
- 軍事倉庫・兵站の拠点
- 中欧遠征の前方基地
- 新しい宗教施設と市場の空間
- 人口移動と居住再編の対象

になった。

この変化は、後のモハーチ、ブダ、ハプスブルクとの戦争にとって重要だった。

しかし、ベオグラード征服だけがその後の展開を決めたわけではない。

## 要塞攻略に必要だったもの

ベオグラードを包囲する軍には、兵士だけでなく、次のものが必要だった。

- 食糧、水、飼料
- 舟、橋、河川航行の知識
- 砲、火薬、弾丸、砲車
- 木材、土、掘削具
- 城壁への射線
- 周辺の堡塁と渡河地点
- 伝令、地図、情報
- 市場と村から得る物資
- 守備側救援を妨げる河川・道路支配
- 包囲軍内部の給与、規律、衛生

要塞戦は、壁の前で起きる戦闘ではなく、

> 河川・道路・集落・市場・倉庫・砲・人間を長期間つなぎ続ける作業

だった。

| 征服後の都市運用 | 守備隊、住宅、穀物、宗教施設、税、港、市場 | 要塞、軍、地方収益、移住者、既存住民 | 人口変動、軍事負担、都市空間の再配分 |

# Layer B — 意味・認識層

## 要塞は何を意味したか

ベオグラードは、各当事者に異なる意味を持っていた。

| 主体 | ベオグラードが意味した可能性 |
|---|---|
| スレイマン政権 | 中欧へ向かう河川・要塞・軍事の接続点 |
| ハンガリー王権 | 南部国境の防壁、王国の防衛能力、政治的威信 |
| 守備隊 | 生存、軍事名誉、食糧、救援、降伏の判断 |
| セルビア系住民 | 住居、共同体、税、宗教施設、移動、戦争の危険 |
| 商人・船員 | 河川通行、港、関税、市場、軍事輸送 |
| オスマン軍事者 | 新政権の最初の大規模な西方成果、給与、戦利品、任官 |
| 後世のオスマン記録 | スレイマンの軍事的正統性、ドナウ線の確保 |
| 後世のセルビア・ハンガリー記録 | 防衛線の喪失、都市の変化、人口移動、国境の転換 |

## 征服後の都市化をどう読むか

征服後、モスク、メスジト、イマレット、守備施設が整えられ、ベオグラードはオスマン軍事都市として成長した。[^tdv-belgrade]

しかし、この変化は、古い都市が消え、新しい都市が無から生まれたことを意味しない。

都市空間では、

- 既存住民の残留・移動
- 新たな軍事者・職人・商人の到来
- 宗教施設の再利用・新設
- 市場と税の再配置
- 要塞防衛と住宅地の関係
- 河川港と軍事倉庫の連結

が同時に進んだ。

# Layer C — 制度・運用層

## セメンディレ県とベオグラード

征服後、ベオグラードはセメンディレ県に編入され、その中心になった。[^tdv-belgrade][^tdv-serbia]

これは、名称だけの変更ではない。

| 制度・運用 | 問われたこと |
|---|---|
| 要塞守備 | どの兵が、どの給与・物資で、どの城壁と河川を守るか |
| 河川艦隊 | ドナウ上の船、港、マルトロス、砲、輸送をどう動かすか |
| 県行政 | 誰が税・裁判・軍役・治安を扱うか |
| 人口再配置 | 残留者、移送者、新来者、軍事者をどこに置くか |
| 都市市場 | 食糧、手工業、港、関税、倉庫をどう維持するか |
| 宗教施設 | モスク、教会、イマレット、共同体をどう扱うか |
| 前方基地 | 中欧遠征に必要な兵站・宿営・道路・渡河をどう整えるか |

## キリスト教徒出身の軍事者を含む国境運用

ベオグラード守備と河川作戦には、セルビア系キリスト教徒出身のマルトロスも配置されたとされる。[^tdv-belgrade]

このことは、国境統治が「宗教的に均質な軍隊」だけで動いていたという想像を複雑にする。

ただし、これを平等な共存の証拠として理想化しない。

軍事雇用、税、身分、忠誠、危険、宗教共同体の位置は、地域・時期・職務ごとに異なっていた。

## RSM上の中心問題

ベオグラード1521年の中心問題は、

> 城が落ちたか。

だけではない。

むしろ、

> ドナウ・サヴァ・要塞・周辺堡塁・市場・住民・軍事輸送を、誰がどのように一つの前方統治拠点へ接続できたのか。

である。

## GMM上の読み方

1521年のベオグラード征服は、城塞の軍事的な取得だけではない。

より慎重には、

> オスマン政権が、河川・要塞・人口・市場・守備・県行政を再配置し、中欧へ向かう長距離軍事行動を支えるための吸収容量を増やそうとした過程

として読むことができる。

# Competing Interpretations

## Interpretation A: ドナウ線の戦略的突破

この解釈は、ベオグラードをドナウ・サヴァ河川線の要塞として重視する。

ここでは、征服は中欧への軍事的通路を拡張した重要な節目となる。

## Interpretation B: ハンガリー南部防衛の限界

この解釈は、ハンガリー王国の政治・財政・軍事的制約、救援の遅れ、周辺要塞の喪失を重視する。

ここでは、ベオグラードの陥落は一つの城の失敗ではなく、防衛線全体の負荷を示す。

## Interpretation C: 都市と人口の再配置

この解釈は、住民移送、守備隊、モスク、イマレット、市場、河川基地化を重視する。

ここでは、征服後の都市運用が戦闘と同じくらい重要になる。

## Interpretation D: モハーチ以前の前方基地形成

この解釈は、1521年を1526年モハーチと1541年ブダの前段階として読む。

ただし、後の展開を1521年の必然的な結果として扱わない。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

1521年のベオグラードで問われていた最大の問題は、

> 城壁を破れるか。

だけではなかったのかもしれない。

むしろ、

- ドナウとサヴァを、敵の防御線ではなく、自軍の輸送・砲撃・補給・連絡の回路へどう変えるか
- ボーグルデレンのような周辺堡塁を確保して、包囲の外側の条件をどう変えるか
- 包囲軍の食糧、馬、砲、橋、船、軍規をどこまで維持できるか
- 城の降伏後、住民、守備隊、港、市場、宗教施設、要塞をどう再配置するか
- ベオグラードを、一度の勝利の記念ではなく、モハーチ以前の前方基地へどう変えるか
- 河川軍事者、マルトロス、地域社会、都市商人を、どの程度新しい統治回路へ組み込めるか

が同時に問われていた可能性がある。

この見方では、ベオグラード1521年は単なる「門を開いた征服」ではない。

> 河川・要塞・人口・市場・軍事輸送・行政を、一つの中欧前方基地として再接続しようとした統治の転換

として見える。

ただし、この構造的説明は、包囲、砲撃、略奪、移送、財産喪失、軍事徴発、都市社会への負担を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

---

# What This Page Does Not Claim

- ベオグラードを、単に「ヨーロッパへの門」とだけ扱わない。
- 1521年の成功を、火砲だけ、あるいは一人の指揮官だけで説明しない。
- ハンガリー側の失敗を、無能や臆病だけに還元しない。
- ベオグラード住民全体が移送されたと主張しない。
- 人口移動の経験を、すべて同じ種類の強制、またはすべて自発的な移住として扱わない。
- 征服後の都市化を、空白地への一方的な新設として扱わない。
- セルビア系・キリスト教徒出身の軍事者の存在を、前線社会の完全な平等の証拠として扱わない。
- ベオグラード征服がモハーチやブダ征服を自動的に決定したと主張しない。
- 構造的説明を、戦争、砲撃、移送、徴発、財産喪失、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
