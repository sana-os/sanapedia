# 1481年オスマン王朝継承危機

> **研究状態:** Provisional  
> **中心問題:** 1481年5月、メフメト2世の死去によって首都の最終命令者が不在になったとき、オスマン政権は、王子、宰相、イェニチェリ、伝令、港、都市秩序、地方軍事者を、どのように止めずに次の統治へ接続しようとしたのか。  
>
> **注意:** このページは、1481年を「バヤズィト2世が兄弟ジェムに勝った事件」とだけ扱わない。首都の暴動、宰相殺害、伝令網の遮断、コルクトの暫定的な代理、王子たちの地理的距離、イェニチェリへの給与、地方軍事者の選択を、同じ危機の異なる面として扱う。

---

# Human Overview

1481年5月3日、メフメト2世がゲブゼ近郊で死去した。

この死去は、ただちに「次のスルタンが誰か」という問題を生んだ。

しかし実際には、危機はそれだけではなかった。

次の問いが同時に発生した。

- イスタンブルで誰の命令が有効なのか
- イェニチェリを誰が落ち着かせるのか
- 王子たちのうち、誰が先に首都へ到達できるのか
- 海峡と道路を誰が使えるのか
- 都市市場、治安、兵士への給与をどう維持するのか
- 大宰相、イスタンブル守護官、地方ベイレルベイ、王子の家臣が誰を支持するのか
- メフメト2世期の土地・ワクフ・収益政策に不満を持った人々が、どの王子に期待するのか
- 外部勢力が王朝内競争をどのように利用するのか

この危機の中心には、バヤズィトとジェムという二人の王子がいた。

バヤズィトはアマスヤを基盤とし、ジェムはカラマン方面にいた。

しかし、両者の地理的距離だけが重要だったのではない。

イスタンブルでは、カラマーニー・メフメト・パシャ、イシャク・パシャ、イェニチェリ、バヤズィトの家臣、ジェムへ連絡しようとする人々が、それぞれ異なる時間感覚と危機感の中で行動していた。

メフメト2世の死は当初隠された。

カラマーニー・メフメト・パシャは、王子たちへ知らせるための手配を行い、ジェム側にも秘密裏に連絡を取ろうとしたとされる。[^tdv-karamani]

しかし情報の遮断は成功しなかった。

死去の知らせは首都へ広がり、イェニチェリの一部がイスタンブルへ入り、カラマーニー・メフメト・パシャは殺害された。[^tdv-karamani][^tdv-bayezid]

その後、イシャク・パシャはバヤズィトに急使を送り、首都の兵士を長く抑えておくことが難しいと伝えた。

さらに、バヤズィトの子コルクトを、父の到着までのナイブ・イ・サルタナト、すなわち暫定的な王朝代理として前面に置いた。[^tdv-ishak][^tdv-korkut]

この措置は、単なる儀礼ではない。

それは、

> スルタンが不在でも、王朝の命令系統が完全には消えていない

ことを示すための緊急の政治的装置だった。

バヤズィトは5月21日にユスキュダルへ到着し、翌22日にイスタンブルで即位手続きが進められた。[^tdv-bayezid]

しかし、危機はそこで終わらなかった。

ジェムはブルサへ入り、名でフトバを読ませ、貨幣を鋳造し、自らの統治を示した。

彼は帝国を分割する提案を行ったとされるが、バヤズィトは統治権を分割できないとして拒否した。[^tdv-bayezid]

1481年6月の新şehir近郊での軍事衝突は、王朝内対立の最初の決定的な局面となった。

ただし、その後ジェムがエジプト、ロードス、フランス、教皇庁などをめぐる長期の政治問題となるため、1481年は単なる短期の即位危機ではない。

それは、

> 首都の継承危機が、アナトリアの軍事競争とヨーロッパ・東地中海の外交問題へ変形していく入口

でもあった。

# Why This Event Matters

1481年継承危機を通じて、次の問いを考えることができる。

- スルタンが遠征中に死去したとき、国家の命令系統はどのように維持されるのか。
- 伝令が届かない、または途中で捕らえられることは、王朝継承をどの程度変えうるのか。
- イェニチェリは、給与を受ける軍事者であるだけでなく、首都の政治秩序を左右する主体だったのか。
- コルクトの暫定代理は、なぜ必要だったのか。
- 大宰相、守護官、王子、地方軍事者、王子の婚姻・家臣ネットワークは、どのように継承危機へ関わったのか。
- 首都を先に掌握することは、なぜ王朝的正統性の重要な条件になったのか。
- 兄弟間の対立は、なぜアナトリアだけでなく、マムルーク、ロードス、教皇庁、フランス、ヴェネツィアなどを巻き込む長期的な外交問題になったのか。
- 「正統な即位」という後世の物語は、首都暴動、殺害、交渉、給与、軍事動員をどこまで見えにくくするのか。

# Source Problem

## 「バヤズィトが即位し、ジェムが敗れた」だけでは足りない

後世の王朝叙述では、1481年はしばしば、

> バヤズィト2世が正統に即位し、ジェムが敗れた年

としてまとめられる。

しかし、この要約だけでは重要な現実が消える。

- メフメト2世の死がどのように隠されたか
- 誰がどの王子に情報を送ろうとしたか
- 伝令がどこで遮断されたか
- イェニチェリがなぜ首都に入ったか
- カラマーニー・メフメト・パシャがなぜ殺害されたか
- 誰が兵士へ約束をし、給与を増やし、都市の騒擾を抑えたか
- コルクトがなぜ一時的に王朝代理として置かれたか
- ジェムがブルサで統治を主張できた条件は何だったか

1481年は、継承の制度が自動的に作動した年ではない。

むしろ、

> 継承制度が不十分なとき、都市・軍事者・通信・財政・家臣ネットワークが、誰を次の支配者として実際に可能にするかを決めた年

として理解する必要がある。

## 史料は、各人の動機を単純化しやすい

カラマーニー・メフメト・パシャ、イシャク・パシャ、イェニチェリ、バヤズィト、ジェムについては、後世の記録がそれぞれ異なる人物像を作っている。

- カラマーニー・メフメト・パシャは、ジェム支持者として描かれやすい。
- イシャク・パシャは、バヤズィト即位の守護者として描かれやすい。
- イェニチェリは、秩序を破壊する集団または王朝を選ぶ集団として描かれやすい。
- バヤズィトは、正統性を回復した人物として描かれやすい。
- ジェムは、悲劇的な王子、または王朝秩序を脅かした請求者として描かれやすい。

しかし、各主体の行動は、血統だけでなく、

- 都市の治安
- 給与
- 土地・収益
- 首都への距離
- 使者と道路
- 家族・婚姻・家臣関係
- 外交的な安全
- 将来の処罰への不安

によっても左右された可能性がある。

# Historical Context

## Before: メフメト2世期の再編が残した負荷

メフメト2世期には、イスタンブル、軍事者、港、土地・収益、ワクフ、官僚組織、宗教共同体が広く再編された。

その結果、オスマン政権はより広い領域で動けるようになった。

しかし同時に、

- 土地・収益の再配分
- ワクフ・私有地への介入
- 軍事費
- 貨幣と給与
- 首都建設の負担
- 宰相家門と新たな高官集団の競争
- アナトリアとルメリの異なる地域条件

が残った。

1481年の危機は、単に父の死から始まったのではない。

それは、こうした負荷が、王朝の最終決定者不在という瞬間に一気に可視化された事件でもあった。

## During: 首都の空白

メフメト2世が死去した時、イスタンブルにはすぐに到着できる成人王子がいなかった。

バヤズィトはアマスヤ、ジェムはカラマン方面にいた。

このため、首都では次の二つの時間が競争した。

- 王子が首都へ到達するまでの時間
- 首都の軍事者・都市民・官僚が秩序を保てる時間

この二つが一致しなければ、継承は血統だけで決まらない。

イシャク・パシャによる急使、兵士への約束、コルクトの暫定代理は、この時間差を埋めようとする行為だった。

## After: 短期危機から長期問題へ

バヤズィトが首都で即位しても、ジェムの請求は消えなかった。

ジェムがブルサで統治を示し、その後アナトリア、エジプト、ロードス、ヨーロッパへ移動したことで、王朝内競争は外部勢力にとって外交的資源となった。

そのため1481年は、

> 首都の即位危機

であると同時に、

> オスマン王朝内の競争が、東地中海・ヨーロッパ外交へ長期に組み込まれる始点

でもある。

# Layer A — 生存・物質的安定性層

## 継承危機は、時間・移動・給与の問題でもある

王朝継承は、理念だけで動かない。

1481年には、次の物質条件が重要だった。

- 王子がどこにいるか
- 首都までの道路と渡河
- ユスキュダルとイスタンブルの海峡移動
- 伝令が安全に通れるか
- 軍事者への給与が維持されるか
- 都市の市場と食糧供給が止まらないか
- 宰相と守護官が命令を出せるか
- 城門、港、船、橋、倉庫を誰が押さえるか
- 略奪や暴動を誰が抑えるか

王子が「正統」であっても、首都へ到達する前に兵士と都市秩序が崩れれば、その正統性は実務的に働かない。

## RBM: 資源需給バランスモデルによる観察

| Function | Demand | Supply | Main Bottleneck |
|---|---|---|---|
| 首都の秩序 | 指揮、兵士への給与、食糧、治安、情報 | 守護官、官僚、軍事者、都市市場、港 | スルタン不在、暴動、命令系統の空白 |
| 王子の移動 | 伝令、道路、馬、船、海峡、護衛 | 地方拠点、家臣、港、都市協力 | 使者の捕縛、距離、競争者の妨害 |
| 軍事者の安定 | 給与、即位祝儀、地位、将来の保証 | 財政、宰相、王子の約束、戦利品期待 | 支払い遅延、誰が支配者か不明 |
| 正統性の可視化 | 玉座、フトバ、貨幣、儀礼、首都 | 王子、官僚、宗教者、都市、軍事者 | 二人の請求者、地域差、情報の不均衡 |
| アナトリアの競争 | 城砦、都市、地方軍事者、補給 | 王子の家臣、地方有力者、収益、道路 | ブルサ・コンヤ・アマスヤの地理的分断 |

## コルクトの代理が示すこと

コルクトは幼い王子だった。

彼が置かれたことは、本人が独自の統治を開始したことを意味しない。

むしろ、

> 首都に「王朝の顔」を置き、命令・給与・儀礼の連続性を示す

必要があったことを示す。

代理は、政治的空白を完全に解消しない。

しかし、空白が暴動・略奪・別の請求者への流動へ変わる速度を遅らせることはできる。

# Layer B — 意味・認識層

## 「正統な継承」は誰にとって何を意味したか

| 主体 | 正統な継承が意味した可能性 |
|---|---|
| バヤズィト側 | 首都への到着、軍事者の承認、父の王朝的継続 |
| ジェム側 | アナトリアにおける王朝的請求、ブルサでの可視性、地域支持 |
| イェニチェリ | 給与、即位祝儀、命令者、軍事的名誉、政治的影響力 |
| 宰相・官僚 | 命令を誰の名で出すか、誰が任官・処罰・財政を決めるか |
| 都市住民 | 略奪の回避、市場の継続、税・裁判・治安の予測可能性 |
| 地方有力者 | 新しい政権との関係、土地・収益・家門の安全 |
| 外部勢力 | オスマン王朝の分裂可能性を外交的に利用できるか |
| 後世の王朝記憶 | バヤズィトの即位を秩序回復として語ること |

## 分割案をどう読むか

ジェムが帝国の分割を提案したとする記録は有名である。

しかし、この提案を単純に「兄弟愛」または「野心」とだけ理解することはできない。

分割案は、少なくとも次の現実を示す。

- ジェム側がアナトリアに独自の政治基盤を持つと考えていたこと
- バヤズィト側が首都とルメリを基盤としていたこと
- 二人の王子の競争が、すでに地理的・軍事的・行政的な分裂へ近づいていたこと
- 王朝統治を二つに分けることが、バヤズィト側には将来の再分裂を固定化する危険に見えたこと

# Layer C — 制度・運用層

## 大宰相職・守護官・王子代理

1481年の危機では、制度が完全に自動で動いたわけではない。

しかし、複数の役割が重なりながら、空白を埋めた。

| 役割 | 主な担い手 | 危機での機能 |
|---|---|---|
| 死去後の行政継続 | カラマーニー・メフメト・パシャ | 死去の秘匿、王子への連絡、首都統制の試み |
| 首都防衛・安定化 | イシャク・パシャ | 伝令、兵士との交渉、都市秩序、バヤズィト支持の接続 |
| 暫定的王朝連続性 | コルクト | 父の到着までの象徴的・制度的代理 |
| 首都到着後の主権確立 | バヤズィト | 即位、給与、任官、命令系統の再編 |
| アナトリアでの競合統治 | ジェム | ブルサ、フトバ、貨幣、軍事動員、地方支持 |
| 軍事的圧力 | イェニチェリ、カプクル、地方軍事者 | 給与・任官・正統性の交渉、首都秩序への直接影響 |

制度的な役割分担が存在していても、誰がそれを承認するかは別問題だった。

1481年は、

> 制度があること

と、

> 制度が実際に従われること

の間にある差を示す。

## イェニチェリと即位祝儀

即位後のバヤズィトによる給与増額と即位祝儀は、単なる祝いではない。

それは、

- 軍事者が新しい支配者を受け入れること
- 首都の武力を秩序維持へ戻すこと
- 宰相殺害後の政治的空白を埋めること
- 将来の軍事動員を可能にすること

に関わる実務だった。

ただし、これを「イェニチェリが王を選んだ」と単純化することもできない。

彼らは重要な政治的主体だったが、王朝、宰相、地方軍事者、都市、財政、道路、港、外部勢力の全てを単独で決められたわけではない。

> バヤズィトとジェムのどちらが「正しい」か。

ではない。

むしろ、

> スルタン不在の数日間に、誰が首都の命令・給与・移動・儀礼・軍事者をつなぎ、王朝が即座に分裂することを防げたのか。

である。

# Competing Interpretations

## Interpretation A: バヤズィトの正統な即位を妨げたジェムの請求

この解釈では、1481年は、バヤズィトが首都で正統に即位し、ジェムがその秩序へ挑戦した事件として理解される。

後世のオスマン王朝史は、この枠組みを強く採用しやすい。

## Interpretation B: 首都を先に接続できた側が統治を可能にした危機

この解釈では、重要なのは血統順位だけではない。

誰がイスタンブル、イェニチェリ、伝令、海峡、宰相・守護官、即位儀礼を先に接続できたかが決定的だったと考える。

## Interpretation C: メフメト2世末期の財政・土地・エリート再編が表面化した事件

この解釈では、継承危機は王子間競争だけではなく、メフメト2世期の土地・ワクフ・給与・宰相家門・軍事者をめぐる緊張が表面化した時点として理解される。

## Interpretation D: 短期の王朝危機が長期外交問題へ変形した事件

この解釈では、1481年の新şehirで終わったように見える危機が、ジェムの国外滞在によって、オスマン王朝とマムルーク、ロードス、教皇庁、フランス、イタリア諸勢力の関係へ組み込まれたことを重視する。

## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

1481年の最大の危機は、

> 次のスルタンが誰か。

だけではなかったのかもしれない。

むしろ、

- 海峡を越えられるか
- 市場と街路の秩序を保てるか
- コルクトのような暫定的な王朝の顔を置けるか
- 宰相殺害後にも命令を出せるか
- 地方軍事者が独自に動き始める前に、新しい報酬と将来像を示せるか
- ジェムの政治基盤がアナトリアで一つの別の王朝中心へ変わる前に、首都とルメリの接続を確保できるか

が問われていた。

この見方では、イシャク・パシャの役割は単なる「バヤズィト支持」ではない。

彼は、

> 継承の空白が、都市暴動・軍事者の離反・王朝分裂へ変わる速度を遅らせようとした人物

だった可能性がある。

ただし、その対応は中立的な行政処理ではなかった。

それはバヤズィトの即位可能性を高め、ジェム側の選択肢を狭めた政治的行為でもあった。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- メフメト2世が特定の後継者を明確に指名していたと主張しない。
- カラマーニー・メフメト・パシャの全行動を、ジェムへの個人的忠誠だけで説明しない。
- イシャク・パシャの行動を、完全に中立的な秩序維持として扱わない。
- イェニチェリを、単純にバヤズィトを「選んだ」唯一の主体として扱わない。
- コルクトが完全なスルタンとして統治したと主張しない。
- バヤズィトの即位が、1481年5月に全オスマン領で即座に受け入れられたと主張しない。
- ジェムのブルサでの請求を、都市住民全体またはアナトリア全域の一枚岩の支持と扱わない。
- 帝国分割提案を、単なる兄弟愛または単純な野心に還元しない。
- 新şehirの敗北によってジェム問題が終わったと主張しない。
- 構造的説明を、暴動、殺害、給与交渉、強制、戦争、処罰、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
