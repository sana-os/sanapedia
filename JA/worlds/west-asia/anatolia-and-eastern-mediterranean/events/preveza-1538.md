# プレヴェザ、1538年

> **研究状態:** Provisional  
> **中心問題:** 1538年のプレヴェザ海戦は、なぜ二艦隊の一日限りの衝突を超えて、エーゲ海・イオニア海・アドリア海の港、島嶼、ガレー船、櫂手、砲、補給、ヴェネツィア、ハプスブルク、教皇庁、オスマン帝国の海上統治回路を再編する事件になったのか。  
>
> **注意:** このページは、プレヴェザを「数で劣るオスマン艦隊が大艦隊を破った」という単純な奇跡譚として扱わない。艦種、浅い湾、風、港、櫂手、砲、情報、連合内の指揮、戦後の港湾・島嶼運用を分けて扱う。

# Human Overview

1538年9月28日、プレヴェザ近海で、バルバロス・ハイレッディン・パシャ率いるオスマン艦隊と、アンドレア・ドーリア率いる神聖同盟艦隊が交戦した。[^tdv-preveza]

この神聖同盟は、教皇パウルス3世の仲介により、ヴェネツィア、ハプスブルク君主国、スペイン、教皇領、ジェノヴァ、マルタ騎士団、ポルトガルなどが参加する形で1538年に組織された。[^tdv-preveza]

背景には、1537年のオスマン軍によるプッリャ・コルフ方面の作戦、バルバロスによるキクラデス・スポラデス諸島への行動、ヴェネツィア領の島嶼・海路をめぐる競争があった。[^tdv-preveza]

オスマン側にとっては、問題は単に「敵艦隊を沈める」ことではなかった。

- イスタンブルとエジプトを結ぶ船舶
- エーゲ海の島嶼
- イオニア海の港
- アドリア海沿岸
- アナトリア・ギリシア沿岸の船員・櫂手・補給
- ヴェネツィアの海上ネットワーク
- ハプスブルクとスペインの海軍力
- 北アフリカのオスマン系海軍拠点

を、どの勢力が安全・課税・軍事・通商の回路へ接続できるかが問われていた。[^tdv-preveza][^guilmartin]

1538年6月、バルバロスは40隻のガレー船を率いてイスタンブルを出発した。

その後、イスタンブルから準備された追加艦隊、エジプトから来た船団、アナトリア諸地域の兵士・櫂手が加わった。[^tdv-preveza]

同時に、オスマン艦隊は島嶼、沿岸、港を移動しながら、兵員、櫂手、砲、食糧、情報、戦利品を扱っていた。

これは一回の会戦へ向かう直線的な航海ではなく、島嶼・港・徴発・補給・威圧・通商の複数の回路が重なる作戦だった。[^tdv-preveza][^ertas-spoils]

神聖同盟側は、数の上ではより大きな艦隊を集めたとされる。

ただし、正確な隻数は史料により異なる。

重要なのは、連合艦隊がヴェネツィア、教皇領、スペイン・ハプスブルク、ジェノヴァ、マルタなど、利害・艦種・指揮系統・財政基盤の異なる勢力から構成されていたことである。[^tdv-preveza]

プレヴェザは、ナルダ湾の入口とその周辺の浅い水域、港、要塞、風、帆船とガレー船の運動性能が重要な場所だった。

大型帆船は砲撃力を持っていたが、浅い湾や無風に近い状況では運動の自由が限られうる。

一方、櫂で動くガレー船は、沿岸や浅い水域で機動しやすかった。[^tdv-preveza][^guilmartin]

1538年9月下旬、バルバロスはプレヴェザ要塞を修理・補強し、湾内外の位置を利用しながら連合艦隊と対峙した。

9月28日の会戦では、オスマン艦隊が三日月形の陣形を取り、砲撃とガレー船の機動を組み合わせたと記録される。[^tdv-preveza]

連合艦隊は、オスマン艦隊を挟撃・包囲しようとしたが、複数回の試みは成功しなかった。

その後、アンドレア・ドーリアはコルフ方向への退却を命じたとされる。[^tdv-preveza]

戦闘後、バルバロスは捕虜・戦利品を得てプレヴェザの拠点へ戻った。

ただし、戦果の正確な隻数と損害は資料間で一致しない。[^tdv-preveza][^ertas-spoils]

海戦は、オスマン政権にとって海軍政策の大きな転換点となった。

一方で、プレヴェザは地中海の全てを一度に固定した出来事ではない。

1538年の後にも、カステルノーヴォ、ヴェネツィアとの和約、北アフリカ、マルタ、ジェルバ、レパントをめぐる競争は続いた。[^tdv-preveza]

このページではプレヴェザ1538年を、

> ガレー船の戦術的勝利であると同時に、港・島嶼・櫂手・捕虜・戦利品・連合外交・海軍補給を再配線した地中海の統治事件

として扱う。

# Why This Event Matters

プレヴェザ1538年は、次の問いを考えるための事件である。

- なぜ海戦は、艦船同士の砲撃だけでなく、港、風、潮流、櫂手、飲料水、食糧、弾薬、修理、島嶼、要塞の問題なのか。
- なぜ大型帆船を多く含む艦隊が、浅い湾や沿岸で必ずしも優位を保てないのか。
- 神聖同盟は、なぜ多数の艦船を集めても、一つの統一された戦略として行動することが難しかったのか。
- ヴェネツィア、ジェノヴァ、教皇庁、スペイン・ハプスブルクは、どのように異なる利害を持っていたのか。
- バルバロスの艦隊は、なぜアナトリア、エジプト、エーゲ海、北アフリカの船員・港・兵員・収益を必要としたのか。
- 戦利品と捕虜は、なぜ勝利の象徴だけでなく、港・宮廷・軍・市場・奴隷化の問題でもあるのか。
- プレヴェザの勝利は、なぜ地中海の競争を終わらせず、カステルノーヴォ、ジェルバ、マルタ、レパントへ続く再配置を生んだのか。

# Source Problem

## 「数で劣る艦隊の奇跡」という語り

プレヴェザはしばしば、少数のオスマン艦隊が圧倒的多数の連合艦隊を破った戦いとして語られる。

しかし、正確な船数は一致しない。

TDVの記事は連合艦隊を大型帆船140隻、ガレー船168隻などと記す一方、他の記録では分類・総数が異なる。[^tdv-preveza]

重要なのは、単純な数ではなく、

- ガレー船と帆船の性能差
- 船の喫水
- 湾口の浅さ
- 風と無風
- 砲撃位置
- 港と補給
- 艦隊の指揮関係
- 連合内部の政治的摩擦
- 沿岸要塞の支援

だった。

## アンドレア・ドーリアの「消極性」

後世の一部の記録は、ドーリアがジェノヴァ系の私的利益やヴェネツィアへの敵意から積極交戦を避けたと描く。

一方で、帆船・ガレー船の性能差、風、浅い水域、兵員上陸の危険、艦隊保全の判断、連合内部の指揮問題も考慮する必要がある。

このページでは、

> ドーリアはなぜ勝てる戦いを避けたのか。

という一問に還元しない。

## オスマン側の『ガザヴァート』

バルバロスの活動を伝える重要な史料に、ムラーディーによる『ガザヴァート・イ・ハイレッディン・パシャ』がある。

これはバルバロスの口述と海軍政策を伝える重要な資料である一方、勝利・正統性・海上行動を強調するガザヴァート文学でもある。[^gazavat-hayreddin]

# Historical Context

## Before: コルフ、島嶼、海上連合

1537年、スレイマン1世とバルバロスは、プッリャ・コルフ方面で陸海共同作戦を試みた。

コルフは決定的に占領されなかったが、その後バルバロスはキクラデス、スポラデス、ナクソス公国に関わる島嶼再編を進めた。[^tdv-preveza]

この動きは、ヴェネツィアにとって単なる領土損失ではなかった。

それは、

- 港
- 船荷
- 関税
- 島嶼の年貢
- 船員
- 海軍基地
- アドリア海・エーゲ海の安全
- レヴァント商業

を揺るがす問題だった。

1538年の神聖同盟は、このような海上回路の再編に対する集団的な対応だった。

## During: 湾・要塞・艦種・補給

プレヴェザでは、ナルダ湾の浅い入口とプレヴェザ要塞が重要だった。

大型帆船は重い砲を搭載できたが、浅い水域・不安定な風・狭い湾口では自由な運動が難しくなる可能性があった。

ガレー船は、櫂を使って風に依存せずに動け、沿岸・浅瀬に接近しやすかった。[^tdv-preveza][^guilmartin]

しかし、ガレー船も自動的に優位ではない。

必要だったのは、

- 櫂手
- 飲料水
- 食糧
- 船体修理
- 火薬
- 砲弾
- 港
- 上陸地点
- 傷病者への対応
- 夜間航行の情報
- 風向・潮流の理解

だった。

## After: 一回の勝利では終わらない海上競争

プレヴェザ後、アンドレア・ドーリア側はカステルノーヴォを占領した。

翌1539年、バルバロスは大艦隊でカステルノーヴォを再奪回した。[^tdv-preveza]

これは、プレヴェザが「海の支配を一日で完成した」出来事ではなかったことを示す。

むしろ勝利は、

- オスマン艦隊の行動範囲
- ヴェネツィアとの交渉
- 連合艦隊の協調困難
- 港湾と島嶼の再配置
- 北アフリカ・イオニア海・アドリア海の接続
- 1540年和約

を、オスマン側に有利な条件で組み替える契機になった。

- 船員
- 兵士

- 塩漬け食料

- 捕虜・戦利品の輸送
- 伝令と情報

| 主体 | 海上安全が意味した可能性 |
|---|---|
| オスマン政権 | イスタンブル・エジプト・北アフリカ・島嶼を結ぶ通行、軍事力、王朝威信 |
| ヴェネツィア | 商船、港、島嶼、年貢、関税、アドリア海・レヴァント通商 |
| ハプスブルク・スペイン | イタリア、ナポリ、北アフリカ、皇帝の威信、対オスマン戦線 |

| 騎士団 | 島嶼、船、捕虜、宗教的軍事活動、次の基地 |
| 船員・櫂手 | 給与、食糧、疾病、風、戦闘、拿捕、生存 |

## 戦利品と捕虜

戦利品と捕虜は、海戦後の周辺的な出来事ではない。

それは、

- 船荷
- 貨幣
- 武器
- 砲
- 奴隷化
- 身代金
- 船員の不足
- 宮廷への報告
- 港湾市場
- 家族の分離
- 宗教的・政治的宣伝

に関わる。

戦利品台帳は、戦争が国家財政と港湾経済に接続していたことを示すが、捕虜となった個人の経験を数字へ還元してはならない。[^ertas-spoils]

# Layer C — 制度・運用層

## 海軍は港と人員の制度で動く

プレヴェザ後のオスマン海軍力は、個々の英雄的操船だけでは維持できない。

| 制度・運用 | 問われたこと |
|---|---|
| 艦隊人事 | 誰が提督、レイス、砲兵、船員、櫂手を統率するか |
| 港湾 | どこで船を修理し、食糧・水・弾薬を積み込むか |
| 櫂手供給 | 誰が櫂を漕ぎ、どの条件で動員されるか |
| 島嶼統治 | 島の収益、港、税、軍事要員、船舶をどう使うか |
| 戦利品処理 | 捕虜、船荷、砲、現金を誰が記録・分配・課税するか |
| 外交 | ヴェネツィア、ハプスブルク、教皇庁、ジェノヴァとどう和戦を調整するか |
| 要塞 | 湾口、港、城、砲台をどの艦隊運用に接続するか |

## 1540年和約と制度的再整理

1540年のヴェネツィアとの和約は、戦闘後の関係を文書化した。

ここで重要なのは、和約が海上競争の終わりではなく、

> 島嶼、港、通商、朝貢、軍事的行動範囲を一時的に制度化する方法

だったことである。

## GMM上の読み方

プレヴェザは、単にオスマン艦隊が「強かった」ことを示す事件ではない。

より慎重には、

> オスマン側が、ガレー船、島嶼、港、櫂手、沿岸要塞、海軍人事、戦利品、外交をより密に接続し、東地中海からイオニア海にかけた海上処理能力を高めた事件

として読むことができる。

ただし、その能力は捕虜、徴発、略奪、島民への負担、敵対勢力との長期競争を伴った。

# Competing Interpretations

## Interpretation A: ガレー船と浅海域の優位

この解釈は、ガレー船の機動力、浅い湾、無風・弱風、沿岸要塞、砲撃位置を重視する。

重要だが、ガレー船も櫂手、水、港、修理、補給なしには機能しない。

## Interpretation B: 神聖同盟の指揮・協調問題

この解釈は、ヴェネツィア、ジェノヴァ、スペイン・ハプスブルク、教皇庁、マルタの利害差を重視する。

アンドレア・ドーリア個人の消極性だけではなく、連合艦隊の制度的な調整困難を問う。

## Interpretation C: 港湾・島嶼・補給の再編

この解釈は、プレヴェザを戦闘日だけでなく、1537–1540年の港、島嶼、航路、櫂手、徴発、和約の連続として見る。

## Interpretation D: オスマン海軍の長期的転換点

この解釈は、プレヴェザを1530年代後半からレパント前までの海軍競争における重要な優位として見る。

ただし、それを地中海全体の恒久的・絶対的支配とは扱わない。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

プレヴェザ1538年の最大の問題は、

> どちらの艦隊が何隻多かったか。

だけではなかったのかもしれない。

むしろ、

- ガレー船を動かす櫂手、水、食糧、港、修理所を、どの海域で維持できるか
- 浅い湾、沿岸要塞、風、夜間航行を、どの艦隊が自らに有利な条件へ変えられるか
- 複数国家から成る連合が、異なる財政・艦種・指揮・利害をどこまで一つの戦術へ統合できるか
- 島嶼・沿岸住民・商人・船員から得る物資と情報を、どの勢力が海軍運用へ接続できるか
- 戦利品と捕虜を、単なる略奪ではなく、財政・人員・港湾市場・政治宣伝の回路へどう組み込むか
- 会戦後の和約と要塞再編を通じて、海戦の勝利をどこまで持続的な海上運用へ変換できるか

が同時に問われていた可能性がある。

この見方では、プレヴェザは単なる「大艦隊を破った海戦」ではない。

> 地中海の港・島嶼・船員・櫂手・要塞・外交を、より強く海軍運用へ接続できる勢力がどこかを試した事件

として見える。

ただし、この構造的説明は、略奪、捕虜化、奴隷化、徴発、宗教的敵対、沿岸住民への負担を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- プレヴェザを「少数が多数を奇跡的に倒した」だけの物語として扱わない。
- 両艦隊の正確な船数、兵員数、砲数、損害数を固定しない。
- 勝利をバルバロス一人の才能だけで説明しない。
- 敗北をアンドレア・ドーリア一人の臆病さ、裏切り、私利だけで説明しない。
- ガレー船が帆船より常に優れていたと主張しない。
- 神聖同盟を一つの利益・一つの意思を持つ組織として扱わない。
- プレヴェザが地中海全体の競争を終わらせたと主張しない。
- 戦利品や捕虜を勝利の抽象的な数字として扱わない。
- 島民、商人、船員、櫂手、捕虜の経験を一律に扱わない。
- 構造的説明を、海戦、略奪、捕虜化、奴隷化、徴発、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
