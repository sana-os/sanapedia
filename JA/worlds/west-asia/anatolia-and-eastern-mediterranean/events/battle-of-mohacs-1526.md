# モハーチ、1526年

> **研究状態:** Provisional  
> **中心問題:** 1526年のモハーチは、なぜ一日の会戦を超えて、ドナウ・ドラーヴァの輸送線、ハンガリー王権、ブダ、ハプスブルク、地域要塞、軍事者、住民、王位継承を再編する長期危機になったのか。  
>
> **注意:** このページは、モハーチを「二時間で終わった戦い」という印象的な語句だけで扱わない。会戦の前には河川、舟橋、雨、道路、砲、軍の集結、政治交渉があり、会戦の後には王位・都市・要塞・地域社会をめぐる長期的な負荷が続いた。

# Human Overview

1526年8月29日、スレイマン1世のオスマン軍と、ラヨシュ2世が率いるハンガリー軍は、ハンガリー南部のモハーチ平原で戦った。[^tdv-mohacs]

会戦はオスマン軍の勝利に終わった。

ハンガリー王ラヨシュ2世は退却中に死亡し、彼の死はハンガリー王位の継承危機を生んだ。[^tdv-mohacs][^tracy-habsburg]

しかし、モハーチは単なる「ハンガリー軍の敗北」ではない。

この事件は、すでに1521年にオスマン側が確保したベオグラードを前方基地として、

- ドナウ川
- ドラーヴァ川
- 舟橋
- 砲と銃兵
- 要塞
- 河川船
- 馬と飼料
- 市場と軍事輸送
- ハンガリー王国の貴族政治
- ハプスブルクとフランスの対立

を一つの遠征へ接続した結果だった。[^tdv-mohacs]

オスマン軍は1526年4月23日にイスタンブルを出発した。

雨、増水、ぬかるんだ道路、渡河の困難により、進軍は当初の計画より遅れた。

そのため軍はセメンディレ経由ではなく、アラジャヒサル方面を経由する経路を取った。[^tdv-mohacs]

パルガル・イブラヒム・パシャはルメリ軍と銃兵・砲兵を率いて先行し、1526年7月にはペーテルヴァーラドを包囲した。

同じ時期、ドナウ川から到着した多数の船は、砲兵輸送、兵員移動、橋梁建設、河川作戦に使われた。[^tdv-mohacs]

ハンガリー側は、ラヨシュ2世、パール・トモリ、フランヨ・バッチャーニらを中心に軍を集めた。

しかし、援軍の到着、軍資金、王国内部の対立、どこでオスマン軍を迎撃するかをめぐる判断には不確実性があった。[^tdv-mohacs]

モハーチの会戦では、ハンガリー側の重装騎兵による急襲が、オスマン軍のルメリ部隊へ向けられた。

オスマン側の記録では、ルメリ軍が左右に開き、その後方の砲車・大砲・イェニチェリ銃兵が射撃を行い、さらにアクンジュ部隊が側背へ回り込んだとされる。[^tdv-mohacs]

この戦術を「火器が騎兵を完全に一方的に破った」と単純化しない。

会戦の結果には、

- ハンガリー側の攻撃時機
- 雨で軟化した地形
- 兵力集結の遅れ
- オスマン軍の防御配置
- 銃兵・砲兵
- ルメリ騎兵とアクンジュの機動
- 指揮と情報
- 王国政治の制約

が重なっていた。[^tdv-mohacs]

会戦後、オスマン軍は9月11日にブダへ入った。

ただし、スレイマンはブダを直ちに恒久占領しなかった。軍は約二週間後に撤退した。[^tdv-mohacs]

ラヨシュ2世の死後、ヤーノシュ・サポヤイとフェルディナント1世がそれぞれハンガリー王位を主張することになった。

これによりハンガリーは、オスマン、ハプスブルク、地域の有力者が交差する長期の競争地帯になった。[^tracy-habsburg]

このページではモハーチ1526年を、

> 戦場での勝敗であると同時に、ドナウ・ドラーヴァ・要塞・ハンガリー王位・ブダ・ハプスブルク国境を再配線した統治危機

として扱う。

# Source Problem

## 「二時間で終わった戦い」という表現

モハーチは、しばしば「二時間で決着した戦い」として記憶される。

TDVは、戦闘が約二時間続いたとする記録を紹介している。[^tdv-mohacs]

しかし、この表現は、戦闘前後の時間を見えにくくする。

実際には、

- 数か月の遠征準備
- 雨と道路の悪化
- 河川船と舟橋
- 要塞攻略
- 軍の集結の遅れ
- 宿営
- 救援可能性
- 王国内部の政治的対立
- 会戦後の捕虜、略奪、埋葬、ブダ入城
- 王位継承危機

があった。

このページでは「短時間の会戦」を否定しないが、それを事件全体の説明にはしない。

## 兵力と損害

兵力・損害は、オスマン資料、ハンガリー資料、後世の研究で異なる。

オスマン側の記録には、ハンガリー軍が約4万から5万人に達したとする説明や、戦場で多数の死者・捕虜が出たという記録がある。[^tdv-mohacs]

ただし、こうした数は、勝利の規模、敗北の衝撃、王朝の正統性を表す記述にもなりうる。

このページでは、固定的な人数を戦闘の核心として扱わない。

# Historical Context

## Before: ベオグラード後のドナウ回路

1521年のベオグラード征服により、オスマン軍はドナウ線に前方拠点を得た。

これは、ハンガリーを直ちに支配できるという意味ではない。

しかし、

- 河川船
- 砲兵輸送
- 宿営
- 市場
- 補給
- 要塞
- 渡河
- 情報
- 軍事者の移動

をより北方へ接続する条件を強めた。[^tdv-mohacs]

1526年の遠征には、ハンガリーだけでなく、フランスとハプスブルクの競争も背景にあった。

パヴィアでフランソワ1世が捕虜になった後、フランス側はオスマン政権へ援助を求めた。

このことは、モハーチを地域戦争だけではなく、中央ヨーロッパと西ヨーロッパの政治競争へ接続した。[^tdv-mohacs]

## During: 雨、河川、舟橋、砲、騎兵

1526年の遠征では、雨とぬかるみが軍の移動に大きく影響した。

オスマン軍は、当初予定していた経路を変更し、要塞を確保しながら前進した。[^tdv-mohacs]

ペーテルヴァーラドとイロクの確保、ドラーヴァ川の舟橋、船による砲と兵士の輸送は、会戦前の重要な条件だった。

戦場では、ハンガリー側の急襲と、オスマン側の防御的な火器・騎兵配置が衝突した。

ここで重要なのは、戦闘を「騎兵対火器」という単純な対立にしないことだ。

火器は、

- 弾薬
- 砲車
- 兵の配置
- 射線
- 時機
- 地形
- 騎兵との連携
- 指揮
- 宿営と補給

に依存していた。

同様に、ハンガリー側の騎兵突撃も、単なる無謀さとして扱えない。

それは、オスマン軍が地形と行軍で分断されていると見えた時点で、迅速に主導権を得ようとする選択だった可能性がある。[^tdv-mohacs]

## After: 王の死と王位の競争

ラヨシュ2世の死は、軍事的敗北を王位の危機へ変えた。

会戦の後、ハンガリーではヤーノシュ・サポヤイとフェルディナント1世が、それぞれ異なる政治基盤を通じて王位を主張した。

この争いは、オスマン、ハプスブルク、トランシルヴァニア、クロアチア、ハンガリー地方社会を巻き込む長期的な国境問題へ進んだ。[^tracy-habsburg]

モハーチは、ハンガリー王国を一日で「消滅」させた出来事としてではなく、

> 王権・王位・要塞・都市・地域有力者の接続が再編され、その後の競争が固定化していく転換点

として理解する必要がある。

# Layer A — 生存・物質的安定性層

## 会戦に至るまでの補給と移動

モハーチ遠征に必要だったものは、兵士や武器だけではない。

- 食糧
- 水
- 馬
- 飼料
- 砲
- 弾薬
- 荷車
- 河川船
- 舟橋
- 木材
- 工兵
- 道路
- 地図と伝令
- 市場
- 宿営
- 給与
- 衛生
- 雨と泥への対応

オスマン軍は、ドナウ・ドラーヴァの河川輸送と舟橋を利用する必要があった。

ハンガリー側は、援軍を集め、食糧を確保し、軍を維持し、王国各地の軍事者を会戦前に集中させる必要があった。

# Layer B — 意味・認識層

## 王国、王位、復讐、保護、恐怖

モハーチは、各当事者に異なる意味を持っていた。

| 主体 | 見えていた可能性のある問題 |
|---|---|
| スレイマン1世 | 王朝威信、ハンガリーの位置、ハプスブルクへの圧力、外交秩序 |
| オスマン軍事者 | 新たな西方遠征、給与、戦利品、名誉、帰還 |
| ラヨシュ2世 | 王国防衛、王位の維持、貴族との関係、援軍、軍費 |
| ハンガリー貴族 | 王の側近、軍費、地方利害、王国の安全、王位の将来 |
| パール・トモリ | 防衛線、渡河阻止、急襲、地形、救援の遅れ |
| サポヤイ派 | トランシルヴァニア、王位、地方政治、オスマン・ハプスブルク間の選択 |
| フェルディナント派 | 婚姻・継承・選挙、ハプスブルク安全保障、オーストリアとの接続 |
| ブダ住民 | 軍の到来、略奪、秩序、宗教施設、財産、避難 |
| 農村住民 | 食糧・馬・労働の徴発、軍の通過、戦闘、避難、損失 |
| 後世の記録者 | 勝利、王の死、王国の転換、国家的喪失、帝国の威信 |

## 「王国の終わり」という言葉

モハーチは、中世ハンガリー王国の終焉を準備した事件としてしばしば語られる。[^tdv-mohacs]

この言い方には重要な真実がある。

しかし、1526年に全てが即時に終わったわけではない。

会戦後も、

- 王位の選出
- サポヤイとフェルディナントの競争
- ブダの地位
- トランシルヴァニア
- クロアチア
- 要塞
- 国境地帯
- オスマンとハプスブルクの停戦・戦争

が長く続いた。

このため、「終わり」という言葉は、政治的秩序の急速な不安定化を示すが、地域社会の全回路が一日で消えたことを意味しない。

# Layer C — 制度・運用層

## 会戦後に問われた統治の問題

モハーチの後、オスマン政権は直ちにハンガリー全土を直接統治したわけではない。

必要だったのは、

| 制度・運用 | 問われたこと |
|---|---|
| 王位 | 誰をハンガリー王として承認・支援・対抗するか |
| ブダ | 占領、撤退、保護、要塞、都市秩序をどう扱うか |
| 要塞線 | ドナウ・ドラーヴァ・クロアチア方面の城を誰が守るか |
| 地方有力者 | 貴族、都市、宗教者、軍事者をどの政体へ接続するか |
| 軍事輸送 | ベオグラード、河川船、道路、宿営、補給をどう維持するか |
| 収益 | 税、農村、都市市場、関税、軍事費をどう再配分するか |
| 外交 | ハプスブルク、フランス、ポーランド、教皇庁との関係をどう扱うか |

## ブダ入城と直接統治は別である

スレイマンは1526年9月にブダへ入った。

しかし、オスマン軍はすぐに撤退した。[^tdv-mohacs]

これは、会戦で勝つことと、都市・王国を持続的に統治することが別の問題であることを示す。

持続的な統治には、

- 守備隊
- 要塞
- 地方有力者
- 税
- 市場
- 住民
- 王位の正統性
- ハプスブルクとの関係
- 河川・道路・補給

が必要だった。

1541年にブダが直接統治下に置かれるまで、この接続は長い競争と調整を経た。

| 設計者 | イブラヒム・パシャ、宰相、砲兵、河川担当者、書記 | 遠征、渡河、兵站、会戦配置、戦後外交をどう組むか |
| 統合者 | 要塞守備、地方貴族、都市有力者、河川船員、商人 | ドナウ、ドラーヴァ、ブダ、地方、軍、収益を誰がつなぐか |
| 実行者 | 騎兵、イェニチェリ、砲兵、工兵、船員、アクンジュ、書記 | 渡河、砲撃、突撃、補給、捕虜、都市管理を誰が担うか |
| 観察者 | 都市住民、農民、商人、宗教者、使節、捕虜 | 会戦と王位危機を脅威、負担、機会、秩序崩壊のどれとして経験したか |
| 監査者 | スルタン、王、貴族、軍、都市社会、後世の歴史家 | 戦術、王位、略奪、税、正統性、国境統治を誰が評価したか |

## RSM上の中心問題

モハーチ1526年の中心問題は、

> どちらの軍が戦場で勝ったか。

だけではない。

むしろ、

> ドナウ・ドラーヴァ・要塞・ブダ・王位・地方貴族・軍事輸送を、誰がどの政治秩序へ接続できたか。

である。

## GMM上の読み方

モハーチは、一方の制度が他方を完全に置き換えた出来事ではない。

より慎重には、

> オスマン側は会戦で軍事的優位を示したが、会戦後のハンガリーでは、王位・要塞・地方社会・収益・国境をどのように持続的に接続するかという新しい統治負荷が生まれた

と読むことができる。

# Competing Interpretations

## Interpretation A: 火器・銃兵・軍事編制の勝利

この解釈は、オスマン側の銃兵、砲、ルメリ軍、アクンジュ、戦術的配置を重視する。

重要だが、雨、地形、渡河、ハンガリー側の集結、政治的制約を外してはならない。

## Interpretation B: ハンガリー王国の政治的・財政的制約

この解釈は、軍費、貴族の協力、援軍の遅れ、王権の脆弱さ、外交的孤立を重視する。

ここでは、敗北は会戦当日の戦術だけではなく、王国の動員能力の問題として読む。

## Interpretation C: ハプスブルク＝フランス競争と中欧の外交

この解釈は、パヴィア、フランソワ1世、カール5世、フェルディナント、オスマン＝フランス接近を重視する。

ここではモハーチは、ハンガリーだけの問題ではなく、ヨーロッパ規模の政治競争に接続される。

## Interpretation D: 王位・ブダ・国境の再編

この解釈は、ラヨシュ2世の死、サポヤイとフェルディナントの競争、ブダ、1541年までの長期的な変化を重視する。

ここでは、会戦後の政治秩序の不安定化が中心になる。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

モハーチ1526年で問われていた最大の問題は、

> オスマン軍がハンガリー軍に勝てるか。

だけではなかったのかもしれない。

むしろ、

- ベオグラードから北へ向かう河川・道路・要塞・市場を、長距離遠征の補給回路としてどう維持するか
- 雨、泥、増水、渡河という物理的な制約を、軍事輸送と会戦の機会へどう変えるか
- ハンガリーの重装騎兵突撃に対して、騎兵、砲、銃兵、待ち伏せ、地形をどう組み合わせるか
- ラヨシュ2世の死後、ハンガリーを直接征服せずとも、どの王位・要塞・地方有力者を通じて影響力を維持できるか
- ブダへ入城した後、軍がそこに留まるための食糧、守備、政治的正統性、地方協力をどこまで確保できるか
- 会戦の勝利を、ハプスブルクへの外交圧力と中欧の国境統治へどう変換するか

が同時に問われていた可能性がある。

この見方では、モハーチは単なる「短時間の決戦」ではない。

> 河川・要塞・軍事輸送・王位・都市・地方有力者・国際外交が、一日の会戦に圧縮され、その後の長い国境戦争として解凍された事件

として見える。

ただし、この構造的説明は、戦闘、略奪、捕虜、財産喪失、徴発、避難、王位をめぐる暴力、地域社会への負担を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

---

# What This Page Does Not Claim

- モハーチを「二時間で終わった戦い」という一句だけで説明しない。
- 会戦の結果を、火器だけ、騎兵だけ、または一人の指揮官だけで説明しない。
- ハンガリー側の敗北を、無能・臆病・裏切りだけに還元しない。
- オスマン軍・ハンガリー軍の正確な人数や損害を確定しない。
- ラヨシュ2世の死を、戦場での即死と断定しない。
- モハーチが1526年にハンガリー全域を完全にオスマン領へ変えたと主張しない。
- ブダ入城を、1541年以後の直接統治と同一視しない。
- サポヤイとフェルディナントの競争を、単純な二者間の争いとして扱わない。
- 地域住民、都市、農村、宗教共同体の経験を一様に扱わない。
- 構造的説明を、戦争、略奪、捕虜、徴発、避難、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
