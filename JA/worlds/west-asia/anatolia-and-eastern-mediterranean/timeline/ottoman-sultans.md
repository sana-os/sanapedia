# オスマン家統治者年表

> **研究状態:** Provisional  
> **対象期間:** おおむね1299年から1922年まで  
> **中心問題:** オスマン家の統治は、どのようにして辺境の政治的連合から、複数地域・複数宗教共同体・複数の軍事制度を抱える帝国的統治へ変化し、またどこで分裂・再接続・再編を経験したのか。  
> **注意:** この年表は「強い支配者の列」ではない。即位、退位、共同統治的局面、空位時代、宮廷政変、地域的自律、継承危機を、統治の接続が変化した局面として記録する。

---

# 【確実なこと（歴史的事実）】

オスマン家の初期統治者については、即位年・死亡年・支配領域の範囲に史料上の不確実性がある。

特に初期段階では、

- 「国家」がいつ成立したのか
- オスマン1世の統治開始を1299年と固定できるか
- オルハンの即位を1324年、1326年、または別の移行過程として理解するか
- 初期支配者を後世の意味で「スルタン」と呼べるか
- 1402年から1413年を、誰か一人の統治として記述できるか

について、研究者のあいだに議論がある。

そのためこの年表は、初期の年号を「絶対に確定した王朝開始日」ではなく、歴史叙述と後世の制度的記憶において広く使われる目安として扱う。

---

# この年表の読み方

## 1. 統治期間は「完全な支配」を意味しない

統治者の在位年は、王朝内での主要な支配者としての期間を示す。

しかし実際には、

- 地方有力者が強い自律性を持つ
- 兄弟・叔父・王子が競争する
- 外部勢力が別の王位請求者を支援する
- 都市や軍事者が条件付きで服従する
- 一部地域が別の支配者・諸侯・帝国の影響下にある

ことがあった。

したがって、在位年は「すべての地域が同じ強度で従った年」ではない。

## 2. 1402–1413年は空位時代として独立して扱う

バヤジト1世のアンカラ敗戦後、オスマン家の支配は複数の王子に分かれた。

この期間には、

- スレイマン・チェレビ
- イーサー・チェレビ
- ムーサ・チェレビ
- メフメト・チェレビ

が、異なる地域・都市・軍事者・外交関係を基盤に統治を主張した。

そのため、空位時代は「メフメト1世までの空白」ではなく、

> オスマン家の統治が、地域ごとに複数の生存戦略として分岐した時期

として扱う。

## 3. 後継者争いは「王朝の失敗」だけではない

継承競争は、王子個人の野心だけで起きたわけではない。

そこには、

- 軍事者の給与と地位
- 都市の安全
- 地方の土地・税収
- 宰相や官僚家系の役割
- 外部勢力との外交
- 宗教共同体の位置
- 王朝の正統性を誰が担うか

が重なっている。

# III. オスマン空位時代 — 統治中心の分裂

## 1402–1413: 空位時代

> **中心問題:** 王朝の中心が失われたとき、都市、軍事者、税、土地、外交、正統性は誰へ接続するのか。

アンカラの戦い後、オスマン家は単一の支配者のもとで統治されなかった。

この時期を、単なる空白や一時的な無秩序として扱うことはできない。

各王子は異なる地域と資源を基盤に、異なる統治の形を試みた。

| Claimant | Main period | Main base or region | Structural emphasis |
|---|---:|---|---|
| Süleyman Çelebi | 1402–1411 | ルメリ、エディルネ | 都市、交易、外交、バルカンの軍事者 |
| İsa Çelebi | 1402–1403 | ブルサ、カレシ、西アナトリア | ブルサ、年長性、西アナトリア、外交 |
| Mehmed Çelebi | 1402–1413 | アマスヤ、内陸アナトリア | 地域的接続、軍事・行政の持続可能性 |
| Musa Çelebi | 1411–1413 | ルメリ、エディルネ | 軍事、貨幣、官職、ルメリ統治の再編 |

# IV. 再統合と継承の安定化

| Field | Content |

| Japanese name | メフメト1世 |

| Main centers | アマスヤ、ブルサ、エディルネ、ルメリ |

| Major challenge | 統一を「戦争の勝利」で終わらせず、日常の統治へ戻すこと |

### Timeline Notes

- 1413年、ムーサの敗北後、メフメトはオスマン家の唯一の主要統治者となった。
- 再統合は、バヤジト1世期への完全な復帰ではなく、空位時代を経て変化した地域関係を再び接続する作業だった。
- 1416年のヴェネツィアとの海上衝突、ベドレッディン関係の運動、バルカンとアナトリアの調整は、統一後にも不安定さが残っていたことを示す。

- 1444年にメフメト2世へ譲位したが、危機の中で軍事指揮へ戻り、1446年には再び正式な統治者となった。
- 譲位と復位は、王朝の柔軟性を示すと同時に、決定権が誰にあるのかをめぐる統治上の緊張を示した。

# V. 帝国的転換

## 1444–1446, 1451–1481: メフメト2世

| Field | Content |
|---|---|
| Name | Mehmed II |
| Japanese name | メフメト2世 |
| First reign | 1444–1446 |
| Second reign | 1451–1481 |
| Main centers | エディルネ、マニサ、ブルサ、イスタンブル |
| Structural significance | 新都、軍事、官僚、法、土地、宗教共同体、海峡統制の帝国的再編 |
| Major challenge | 征服後の都市と帝国を、持続可能な統治へ変えること |

### Timeline Notes

- 第一次在位期には、若いメフメト2世、ムラト2世、宰相、イェニチェリ、外部勢力のあいだで、決定権が不安定だった。
- 1446年のブチュクテペ事件後、メフメトはマニサへ移り、ムラト2世が復位した。
- 1451年の再即位後、メフメトはルメリ・ヒサルを建設し、1453年にコンスタンティノープルを掌握した。
- 1453年後、イスタンブルは軍事的勝利の記念碑だけでなく、人口、港湾、宗教共同体、法、寄進、交易、官僚、教育を抱える帝国的中心として再編された。
- 1461年のトレビゾンド併合、1463–1479年のヴェネツィアとの戦争、1473年のオトルクベリの戦いは、帝国的統治の地理的範囲と資源負荷を拡大した。
- 1481年の死後、バヤジト2世とジェム・スルタンの継承競争が発生した。

**Related Page:** [メフメト2世](../people/mehmed-ii.md)

# SANA Structural Reading

## 王朝の長期的な問い

この年表を通して見えるのは、オスマン家が常に同じ問題を抱えていたわけではないということである。

| Period | Main Structural Question |
|---|---|
| Osman I / Orhan | 地域的な軍事・都市・共同体の接続をどう作るか |
| Murad I / Bayezid I | 広域化と急速な統合をどう維持するか |
| Interregnum | 中心が失われたとき、統治はどこに残るか |
| Mehmed I / Murad II | 分裂後の統治をどう再び反復可能にするか |
| Mehmed II | 帝国規模の都市・軍事・官僚・宗教共同体をどう接続するか |
| 16世紀 | 広がる帝国の資源・法・軍事・地方統治をどう維持するか |
| 17–18世紀 | 軍事、貨幣、地方、宮廷、交易の変化にどう適応するか |
| 19世紀 | 改革・中央統制・国際秩序の圧力をどう扱うか |
| 20世紀初頭 | 帝国的王朝統治と国民国家的主権の衝突をどう処理するか |

## 空位時代は例外ではなく、観察窓である

1402–1413年の空位時代は、オスマン史の「例外的な混乱」として扱われがちである。

しかし、この時期はむしろ、通常は見えにくい統治の構造を露出させる。

- 都市は誰へ城門を開くのか
- 軍事者は誰の命令を実行するのか
- 税と土地は誰の統治を支えるのか
- 外部勢力は誰を交渉相手として選ぶのか
- 王朝の血統は、資源や安全がなければどこまで機能するのか

この意味で空位時代は、オスマン政治体の「壊れた時間」ではなく、

> 統治を支える接続が、どこに存在していたかを可視化する時間

でもある。

# What This Timeline Does Not Claim

- 1299年を絶対に確定したオスマン国家の建国年として扱わない。
- 初期統治者の在位年・称号・支配範囲が完全に確定しているとは主張しない。
- 在位年が、すべての地域における完全で均一な支配を意味するとは主張しない。
- 空位時代を、統治者不在の「空白期間」として扱わない。
- 継承競争を、王子個人の性格や野心だけで説明しない。
- オスマン史を、単純な上昇・停滞・衰退の一方向的な物語として扱わない。
- 中央集権化を、単純な進歩または後退として扱わない。
- 改革を、中央が一方的に命令して社会が受け取るだけの過程として扱わない。
- 帝国の統治を、戦争、徴税、強制移住、処刑、宗教的圧力、支配から切り離して美化しない。
- SANAの構造的説明を、歴史上の暴力や不平等の免罪として扱わない。
