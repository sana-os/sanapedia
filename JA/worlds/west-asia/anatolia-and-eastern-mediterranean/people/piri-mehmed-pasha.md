# ピリ・メフメト・パシャ

> **研究状態:** Provisional  
> **中心問題:** セリム1世期の急速な軍事拡張と、スレイマン1世初期のより広い統治課題の間で、ピリ・メフメト・パシャは、財務・補給・新領土・首都継承・要塞・海路を、どこまで反復可能な行政へ翻訳できたのか。  
>
> **注意:** このページは、ピリ・メフメト・パシャを「制度を一人で作った人物」として扱わない。彼の仕事は、財政、書記、軍、船、首都、地方官、カーディー、ワクフ、スルタンの決定を接続する媒介として扱う。

# Human Overview

ピリ・メフメト・パシャは、セリム1世とスレイマン1世に仕え、1518年から1523年まで大宰相を務めた。

彼の経歴は、アマスヤの裁判所書記、地方カーディー、ワクフ管理、財務官、宰相、イスタンブル守護、大宰相、そしてシリヴリの退隠へと移る。[^tdv-piri]

この経歴は、単なる昇進の物語ではない。

そこには、

- 文書と裁判
- 財務と給与
- 軍事遠征の補給
- 新領土の検地
- 首都の守護
- 港と船
- 要塞と道路
- 大宰相職とスルタンへの近接
- ワクフと都市施設

を接続する実務がある。

1514年のチャルディラーン遠征では、セリム1世がサファヴィー軍との戦闘をめぐって開いた協議で、即時に戦う方針を支持したとされる。

戦後には、タブリーズに残された財貨・軍需品を管理下に置く仕事を命じられ、同年10月に宰相となった。[^tdv-piri]

1516年、セリム1世のエジプト遠征中にイスタンブル守護へ任じられた。

このとき、エジプトの軍に生じた給与問題へ対応し、短期間で82隻の船を準備して、食糧と大型砲二門を送ったと記録される。[^tdv-piri]

1518年1月25日、ユヌス・パシャの処刑後に大宰相へ任命された。

その後、ディヤルバクル周辺と北イラクで、サファヴィーの影響を弱め、獲得地域の検地を行わせたとされる。[^tdv-piri]

1520年、セリム1世死去後もスレイマン1世の大宰相を約三年間務めた。

ベオグラードを「ヨーロッパの鍵」と位置づけ、同地の優先をスレイマンに働きかけ、1521年の包囲に参加した。

翌年はロードス遠征にも参加し、島嶼・要塞・港・海路をめぐる問題に関わった。[^tdv-piri]

1523年、彼は罷免され、スレイマン1世の近臣であったパルガル・イブラヒム・パシャが大宰相となった。

退任には、エジプトからイスタンブルへ移送されていた旧マムルーク系有力者・職人・学者の釈放をめぐる収賄疑惑、第二宰相アフメト・パシャの動き、イブラヒムへのスレイマンの強い近接が重なったと記録される。[^tdv-piri][^tdv-ibrahim]

ピリ・メフメト・パシャは、退任後にシリヴリへ退き、1532年秋に死去した。

毒殺説は、イブラヒム・パシャや息子との関係で語られるが、確立した事実ではない。[^tdv-piri]

このページでは彼を、

> セリム1世の軍事的拡張を、スレイマン1世初期に必要となる財務・補給・検地・首都・要塞・海路の行政へ接続しようとした大宰相

として扱う。

- 軍事拡張は、どのように財務、給与、船、食糧、重砲、道路、検地、港の問題へ変わるのか。
- 大宰相は、スルタンの軍事決定をどのように首都・州・軍・財政・文書へ翻訳するのか。

- 大宰相の能力と経験は、なぜ必要であると同時に、スルタンに近い別の家臣が台頭する際には再配置されうるのか。

# Source Problem

## 「制度の橋渡し役」という人物像

ピリ・メフメト・パシャは、セリム1世からスレイマン1世への移行を支えた「制度の橋渡し役」として描きやすい。

この読み方には根拠がある。

彼は財務、検地、首都守護、軍事補給、大宰相職、要塞遠征に関わった。

ただし、そこから、

> 彼が一人で新領土統合の設計図を作った。

と結論づけることはできない。

軍事者、財務官、カーディー、書記、地方官、船員、港湾関係者、既存の都市有力者、スルタン自身が関わった。

## 1523年の退任

退任は、単純な「敗北」でも、単純な「陰謀」でもない。

記録には、

- 旧マムルーク系の釈放をめぐる収賄疑惑
- ルメリ・アナトリア両カズアスケルによる調査
- 第二宰相アフメト・パシャの働きかけ
- パルガル・イブラヒム・パシャへのスレイマンの近接
- 年齢と長期在任

が重なる。

これらのどれが決定的だったかを、単一の物語に固定しない。

# Historical Context

## Before: 財務・文書・遠征

ピリ・メフメト・パシャが大宰相になる以前、オスマン政権はすでに、

- 1511年の王子間競争
- シャークル蜂起
- サファヴィー朝との東方緊張
- チャルディラーン
- ドゥルカディルの再編
- シリア・エジプトへの進出

を経験していた。

拡張は、軍旗と城門だけで維持できない。

必要なのは、兵士の給与、食糧、輸送、文書、検地、地方官、港、都市市場、税、旧来の有力者との関係だった。

ピリ・メフメト・パシャの財務・書記・法務の経歴は、この時期の需要と接続していた。

## During: 首都守護と補給

1516年のイスタンブル守護は、単に「首都を守る」役ではない。

セリム1世の主力軍が南方にあるとき、イスタンブルでは、

- 軍事者の給与
- 食糧・物資
- 港と船
- 砲
- 首都の安全
- 税と市場
- 命令と書状

が止まらずに動く必要があった。

82隻による食糧・重砲輸送は、遠征を支える物資と、首都の行政能力がつながっていたことを示す。

## After: スレイマン初期と大宰相職の再編

1520年、スレイマン1世は大きな成人王子間競争なしに即位した。

しかし、大宰相職の意味は変わり始めた。

ピリ・メフメト・パシャは、セリム1世期からの経験と制度知識を持つ。

一方、パルガル・イブラヒム・パシャは、スレイマンの王子時代から近い家臣だった。

1523年の交代は、

> 長期経験を持つ大宰相から、若いスルタンに直接近い家臣へ、宮廷中心の媒介役が移る

転換として読める。

これは、ピリ・メフメト・パシャが不要だったことを意味しない。

むしろ、スレイマン初期の政権が、軍事・外交・宮廷の役割配置を別の形で組み直したことを示す。

# Layer A — 生存・物質的安定性層

## 軍事拡張を維持する条件

セリム1世期からスレイマン初期にかけて、政府が動かす必要のあったものは、

- 銀、貨幣、税、関税
- イェニチェリや騎兵への給与
- 食糧、飼料、水、倉庫
- 船、港、帆、船員、重砲
- 道路、橋、渡河地点、城砦
- 文書、検地、地図、伝令
- 地方官、カーディー、書記、徴税者
- 首都の市場、治安、物価
- ワクフの店舗、村、施設、職員

だった。

1516年の輸送は、この複数の需要が首都に集中し、船と港を通じて南方遠征へ接続された例として読むことができる。

# Layer B — 意味・認識層

## 実務家という人物像

ピリ・メフメト・パシャは、後世の記録で「経験豊かな国家人」として描かれやすい。

この像は、

- 財務経験
- 遠征参加
- 首都守護
- 大宰相職
- 文人保護
- ワクフ

をまとめるためには便利である。

ただし、実務能力は中立ではない。

軍への給与を整えることは、兵士にとっては保護や期待でありうる。

同時に、それは税・収益・物資・労働を多くの地域社会から引き出す統治でもあった。

| 主体 | ピリ・メフメト・パシャの実務が意味した可能性 |
|---|---|
| セリム1世 | 遠征と新領土を維持する財務・文書・軍事の媒介 |
| スレイマン1世 | 父の時代からの経験を持つ大宰相、または再配置すべき旧世代の中心 |
| 軍事者 | 給与、補給、砲、指揮、任官 |
| イスタンブル住民 | 首都の安定、港、軍事輸送、市場への負荷 |
| 新領土の地域社会 | 検地、税、軍役、裁判、地方有力者との関係 |
| 文人・学者 | 保護、任官、宮廷への接近、宗教・文化の記録 |
| シリヴリ住民 | 食事、学び、宿泊、店舗、施設職員、ワクフ管理 |
| 後世の記録者 | 経験ある大宰相、善政の人物、毒殺伝承の主人公 |

# Layer C — 制度・運用層

## 首都守護は都市と遠征のあいだにある

イスタンブル守護は、城門や治安だけの役職ではない。

1516年には、

- 首都の命令
- 兵士給与
- 財政
- 港
- 船
- 食糧
- 重砲
- 遠征軍への情報と物資

が一つの運用問題になった。

このため、ピリ・メフメト・パシャの役割は、首都とエジプトを二つの別世界として扱わず、同じ軍事・行政の流れとして接続することだった可能性がある。

## 検地・財務・地方行政

検地は、単に土地を数えることではない。

そこには、

- 誰が村・土地・収益を管理するか
- 誰が軍役を負うか
- 誰が税を集めるか
- 旧来の宗教施設・有力者・地方共同体の収益をどう扱うか
- 国家がどの範囲まで記録と監査を行うか

が関わる。

ピリ・メフメト・パシャが北イラクなどで関わった検地は、軍事的獲得を行政的に扱うための重要な過程だった。

同時に、それは地域社会の既存の収益・権利・移動・負担を変える可能性を持つ。

## ワクフとシリヴリ

1521年のワクフ文書によれば、シリヴリ複合体にはモスク、メドレセ、宿泊施設、イマレット、食堂、学校、厨房、倉庫、パン工房、厩、店舗、ムヴァッキトハーネ、墓域があった。[^tdv-kulliye]

これは、礼拝だけではない。

- 食事
- 学び
- 時間管理
- 宿泊
- 移動と厩
- 市場・店舗
- 職員
- 収益
- 家門記憶

を接続する制度だった。

| 統合者 | 宰相、カーディー、州知事、港湾関係者、軍事者 | 首都、新領土、軍、収益、港を誰が接続するか |

## RSM上の中心問題

ピリ・メフメト・パシャの中心問題は、

> 彼が有能な大宰相だったか。

だけではない。

むしろ、

> 急拡張した政権に必要な財務・補給・文書・検地・首都・要塞・海路を、一つの実務的連鎖として誰がつなぎ、その媒介がいつ別の宮廷近接性へ再配置されるのか。

である。

| Layer | Demand | Supply | Observed Gap |

| C — 制度・運用層 | 検地、財務、首都守護、軍事輸送、任官、ワクフ | 大宰相、財務官、書記、カーディー、港湾、地方官 | 地域差、既存権利、スルタンとの距離、役職競争 |

## GMM上の読み方

ピリ・メフメト・パシャ期は、

> 軍事的獲得を、財務・補給・検地・文書・首都・地方の反復可能な運用へ変えようとする過程

として読むことができる。

しかし、その変換は自動的ではない。

それは、税、労働、収益、移動、既存権利、地域社会への介入を伴う可能性がある。

# Competing Interpretations

## Interpretation A: セリム1世からスレイマン1世への橋渡し役

この解釈では、ピリ・メフメト・パシャは、セリム1世の急拡張を、スレイマン初期に必要な財務・補給・検地・要塞・首都行政へ接続した人物として理解される。

## Interpretation B: 財務・補給の大宰相

この解釈は、首席財務官、イスタンブル守護、82隻の輸送、検地活動を重視する。

この見方では、彼の重要性は戦場の英雄性ではなく、軍事力が実際に動く条件を整える実務にある。

## Interpretation C: 旧世代の経験者から新しい近臣政治への移行

この解釈では、1523年の退任を、単なる失敗ではなく、セリム1世期の経験者から、スレイマンに直接近いイブラヒム・パシャへ大宰相職の重心が移る転換として読む。

## Interpretation D: 文人保護者とワクフ創設者

この解釈では、文人保護とシリヴリ複合体を、政務経験を都市・学び・食事・旅人・収益・家門記憶へ変換する制度として読む。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

ピリ・メフメト・パシャの最大の課題は、

> どの遠征を成功させるか。

だけではなかったのかもしれない。

むしろ、

- 新しく獲得した地域を、軍事的勝利の後にどう課税・検地・裁判・軍役へ接続するか
- 主力軍がエジプトにいるとき、イスタンブルの銀、船、食糧、砲、港をどう止めずに動かすか
- ベオグラードとロードスを、別々の勝利ではなく、道路・要塞・港・海路・補給の接続問題としてどう扱うか
- 年長で経験ある大宰相として、若いスルタンに近い新しい家臣団とどこまで役割を分けられるか
- 退任後も、ワクフと都市施設を通じて、知識・収益・家門記憶をどう残すか

が同時に問われていた可能性がある。

この見方では、彼は単なる「有能な官僚」ではない。

> 軍事的拡張を、首都・財務・補給・検地・都市施設へ翻訳しようとした媒介者

として見える。

ただし、その媒介は中立的ではない。

検地、税、軍役、軍事補給、港湾動員、地域社会への介入を伴った可能性がある。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- ピリ・メフメト・パシャが一人でセリム1世期の新領土統合を設計したとは主張しない。
- 学問・法務系の経歴を、後の政策すべての直接原因として扱わない。
- 1514年のチャルディラーン勝利を、彼一人の軍事判断に帰属させない。
- 1516年のエジプト遠征補給を、彼個人だけの成果として扱わない。
- 検地を、全地域の即時・均一な統合とみなさない。
- 1520年の継承を、彼が完全に設計した摩擦のない移行として扱わない。
- 1523年の罷免を、アフメト・パシャまたはイブラヒム・パシャ一人の陰謀として説明しない。
- 1532年の死因を毒殺と確定しない。
- ワクフを、純粋な慈善または費用のない福祉制度として扱わない。
- 文人保護を、政治的中立や全面的な宗教的寛容の証拠として扱わない。
- 構造的説明を、戦争、税、徴発、検地、拘束、処罰、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
