# イシャク・パシャ

> **研究状態:** Provisional  
> **中心問題:** スルタン不在、都市騒擾、王子間競争、軍事者の給与、伝令網の断絶が重なった1481年に、イシャク・パシャは首都・軍事者・暫定王朝代理・バヤズィトの到着を、どのように一つの継続する統治関係へ接続しようとしたのか。  
>
> **注意:** このページはイシャク・パシャを、中央集権を一人で作った人物として扱わない。また、同名官人の記録を無批判に一人へ集めない。

# Human Overview

イシャク・パシャ・ビン・イブラヒムは、メフメト2世とバヤズィト2世の時代に活動した高官である。

この人物の記事は、経歴の華やかさより先に、**同名人物の混同**から始める必要がある。

同時代には、イシャク・ビン・アブドゥッラーを含む複数のイシャク・パシャがいた。

後世の年代記、行政史、建築史では、彼らの官歴、軍事行動、寄進、出自がしばしば混同される。

このページが対象とするのは、イネギョルのワクフ資料と1481年の首都危機に比較的確実に結びつく、イシャク・ビン・イブラヒムである。[^tdv-ishak]

彼について比較的安定して追えるのは、

- 1463–64年のアナトリア・ベイレルベイ職
- 1481年のイスタンブル守護
- バヤズィト2世への急使
- コルクトの暫定代理
- 1481年以後の大宰相職
- 1483年のサロニカ移任
- イネギョル、イスタンブル、サロニカでのワクフと建築

である。[^tdv-ishak]

1481年の彼は、単にバヤズィトを支持した人物ではなかった。

メフメト2世の死後、首都では、

- 大宰相の殺害
- 軍事者の動揺
- 王子への使者の不達
- 市場と都市秩序の不安
- 王朝の最終命令者不在
- ジェムがアナトリアで先に別の政治中心を作る可能性

が同時に生じていた。

イシャクはバヤズィトへ複数の急使を送り、兵士を長く抑えられないと訴えたとされる。

そしてバヤズィトの子コルクトを、父を代表するナイブ・イ・サルタナトとして前面に置いた。[^tdv-ishak]

この措置は、王朝の空白を消したわけではない。

しかし、

> 首都にはまだ王朝の代理があり、命令・給与・儀礼・守備は完全には途切れていない

と示す実務的な装置だった。

その後のイシャクは、バヤズィト2世の大宰相として、王朝継承後の官僚・軍事・都市の接続を扱った。

ただし、彼自身も独立した権力中心として見られるようになり、1483年に大宰相職を離れたとされる。[^tdv-ishak]

このページではイシャク・パシャを、

> 王朝の空白を消すことはできなくても、その空白が首都暴動・軍事者の離反・即時の分裂へ変わる速度を遅らせようとした媒介者

として扱う。

# Source Problem

## 同名人物の混同

イシャク・パシャの記事で最も重要な問題は、同時代に複数のイシャク・パシャがいたことである。

とくに、

- イシャク・ビン・アブドゥッラー
- イシャク・ビン・イブラヒム
- 「サル」などの別称で現れるイシャク

の官歴・建築・軍事行動は、後世の記録で重ねられやすい。

このため、次の主張は慎重に扱う必要がある。

- 1450年代の各軍事遠征への参加
- 1460年代・1470年代の正確な大宰相就任・離任年
- 出自、教育、デヴシルメかどうか
- アクサライ住民移送の直接責任
- イスタンブルの建築の厳密な帰属
- 婚姻関係の細部

このページでは、ワクフ資料、1481年の書状・危機記録、建築資料、TDVが慎重に整理する官歴を中心に置く。

## 「秩序維持者」という像の限界

イシャクは、1481年に首都秩序を保った人物として記憶される。

これは重要な記録である。

しかし、彼の行動は完全に中立ではない。

コルクトを代理に置き、バヤズィトの到着を急がせ、軍事者を約束で落ち着かせた行為は、バヤズィトの即位可能性を高めた。

したがって、彼は「秩序」一般を守ったというより、

> バヤズィトの即位を中心に、首都秩序を再接続した

人物として理解する必要がある。

# Historical Context

## Before: メフメト2世期の拡張と、同名官人の影

メフメト2世期は、軍事遠征、都市整備、土地・収益の再編、官僚家門の競争が重なった。

イシャク・パシャの初期官歴が混同されやすいこと自体、この時期の高官人事を「一人の人物の一直線の昇進」として書けないことを示す。

高官の役割は、

- アナトリア・ルメリの地方統治
- 軍事動員
- 城砦・道路・収益
- 王子家臣との接続
- イスタンブルの都市秩序
- ワクフと地域的基盤

にまたがっていた。

## During: 1481年の首都における接続危機

1481年に必要だったのは、新しいスルタンの名前だけではない。

首都で、

- 兵士が暴力へ流れないこと
- 市場が完全に止まらないこと
- 王子へ情報が届くこと
- 道路・海峡が使えること
- 誰かが命令を出せること
- 代理が儀礼と給与を担えること

が必要だった。

イシャクは、コルクトを代理として置くことで、王朝の「顔」と制度的な空白の間をつなごうとした。

これは、王朝の中立的な継続ではない。

バヤズィトの即位を可能にする方向へ、首都の時間を組み直す政治だった。

## After: 大宰相から地域的寄進者へ

1483年以後、イシャクはサロニカへ送られた。

ここでのアラジャ・イマレットは、モスクだけでなく、滞在者を受け入れるザヴィエ的機能と、ワクフによる収益・職務の枠組みを持っていた。[^tdv-alaca]

イネギョルの複合体も、モスク、メドレセ、墓廟、イマレット、ハン、厩を含む。

これらは、単なる「引退後の慈善」ではない。

都市、移動、滞在者、教育、商業、家門記憶、収益を、長期的に結びつける制度的な装置だった。

---

# Layer A — 生存・物質的安定性層

## 首都危機に必要な資源

1481年の首都危機では、理念だけでなく、次の資源が必要だった。

- 軍事者への給与と即位祝儀
- 食糧・市場・街路の安全
- 伝令、馬、道路、船、海峡
- 城門、港、守備隊
- 王子家臣と地方官の協力
- 命令を文書化・伝達する書記
- 混乱時に使える収益と備蓄

イシャクの役割は、軍事的な指揮だけでなく、この資源が首都の暴力と分裂へ流れないようにすることだった可能性がある。

## RBM: 資源需給バランスモデルによる観察

| Function | Demand | Supply | Main Bottleneck |
|---|---|---|---|
| 首都の秩序 | 給与、食糧、守備、情報、命令 | 守護官、軍事者、港、都市市場、財政 | スルタン不在、暴動、時間不足 |
| 王子の到着 | 伝令、道路、馬、船、海峡、護衛 | アマスヤ基盤、地方官、都市協力 | 使者不達、距離、競争者の妨害 |
| 暫定代理 | 玉座、儀礼、書記、兵士への約束、守備 | コルクト、イシャク、首都の官僚・軍事者 | 代理の限定的権限、二人の請求者 |
| 大宰相の統治 | 宰相人事、軍事者、官僚、収益、都市秩序 | 王朝的信任、家臣、人脈、財政 | スルタンとの距離、他の高官、軍事者の支持 |
| ワクフ・都市基盤 | 収益、職人、建築、管理者、地域協力 | 土地、店舗、寄進、地方経済 | 維持費、既存権利、政治的変動 |

# Layer B — 意味・認識層

## イシャクは「秩序」そのものではない

1481年のイシャクは、後世の記録では秩序を守った人物として描かれやすい。

しかし、秩序は誰にとっての秩序かを問う必要がある。

| 主体 | イシャクの行動が意味した可能性 |
|---|---|
| バヤズィト側 | 首都への道を開き、即位を可能にする支援 |
| ジェム側 | 首都での選択肢を狭める、競争者側の政治行為 |
| イェニチェリ | 給与・約束・指揮系統の再設定 |
| イスタンブル住民 | 略奪と騒擾の抑制、または軍事者への譲歩の負担 |
| 高官家門 | 新しい政権下での任官・安全・競争の再配置 |
| サロニカ・イネギョルの都市社会 | ワクフを通じた施設・収益・地域記憶の形成 |
| 後世の王朝史 | バヤズィト即位を可能にした忠臣像 |

## 大宰相の経験が「必要」と「危険」を同時に生むとき

イシャクの1481年の経験、人脈、軍事者への影響力は、首都危機では必要だった。

しかし、同じ能力は、バヤズィト2世の統治が落ち着くにつれて、スルタンから見れば独立した重心にもなりうる。

1482年以後の人事競争と1483年の離任は、

> 危機をつなぐために必要だった媒介者が、危機後にはどのように再配置されるのか

という問題を示す。

---

# Layer C — 制度・運用層

## 首都守護・アタベグ・大宰相

1481年には、複数の制度的役割が重なった。

| 役割 | 主な機能 |
|---|---|
| イスタンブル守護官 | 城門・守備・都市秩序・軍事者への対応 |
| アタベグ | 王子代理を保護し、政務の連続性を支える |
| ナイブ・イ・サルタナト | 不在の支配者を代表する暫定的な王朝の顔 |
| 大宰相 | 即位後の命令、任官、財政、軍事、都市、外交をつなぐ |
| ワクフ管理 | 収益、職務、施設、滞在者、家門記憶を継続させる |

これらは自動的に機能したのではない。

役職の権威は、軍事者、官僚、都市、王子、財政が承認することで初めて実務になる。

## ワクフを都市の接続装置として読む

イネギョル複合体とアラジャ・イマレットは、宗教建築だけではない。

そこには、

- 礼拝
- 学び
- 宿泊・滞在者の受け入れ
- 商業・店舗・ハン
- 厩と移動
- 収益と管理
- 墓廟と家門記憶
- 都市空間の編成

が関わる。

ワクフは保護や支援を生みうる。

同時に、土地・収益・労働・権威を特定の制度へ固定する装置でもある。

# Role System Model

| 役割 | 主な主体 | イシャク期に見える問い |
|---|---|---|
| 決定者 | バヤズィト2世、王朝成員 | 誰が継承・任官・軍事・財政を最終決定するか |
| 設計者 | イシャク、宰相、書記、財政実務者 | 危機を通信・給与・儀礼・命令へどう翻訳するか |
| 統合者 | 首都守護官、王子家臣、軍事者、都市有力者 | 首都、アナトリア、軍事者、地域社会を誰が接続するか |
| 実行者 | イェニチェリ、守備隊、伝令、船員、徴税者、職人 | 治安、通信、移動、給与、建築、ワクフ運用を誰が担うか |
| 観察者 | 都市住民、商人、使節、宗教者、地方有力者 | 誰が安定・機会・負担をもたらすと見られたか |
| 監査者 | 軍事者、都市社会、法学者、ワクフ関係者、後世の記録者 | 給与、財産、命令、寄進、正統性を誰が評価したか |

## RSM上の中心問題

イシャク・パシャの記事の中心は、

> 彼がバヤズィトを支持したか。

だけではない。

むしろ、

> 継承空白のなかで、首都の命令・給与・伝令・儀礼・軍事者をつなぐ媒介者が、どのように一時的な必要性から恒常的な政治重心へ変わり、さらに再配置されるのか。

である。

| Layer | Demand | Supply | Observed Gap |
|---|---|---|---|
| A — 生存・物質的安定性層 | 食糧、給与、治安、道路、海峡、伝令、建築維持 | 首都財政、軍事者、港、都市市場、ワクフ | スルタン不在、暴動、通信遮断、資源の不均衡 |
| B — 意味・認識層 | 王朝連続性、軍事者の信頼、都市の安心、正統性 | 血統、代理、即位儀礼、貨幣、フトバ、家門記憶 | バヤズィトとジェムの競合、後世の忠臣像 |
| C — 制度・運用層 | 首都守護、代理、任官、給与、ワクフ、地方統治 | 守護官、大宰相、アタベグ、書記、軍事組織、地方官 | 同名人物混同、役割競合、スルタンへの近接の変化 |

## GMM上の読み方

イシャク・パシャの経歴は、完成した官僚制度の直線的な昇進ではない。

むしろ、

> 危機時には首都・軍事者・王朝代理を接続する能力が必要とされ、その能力が危機後にはスルタンとの距離や高官間競争によって再配置される

ことを示す。

# Competing Interpretations

## Interpretation A: バヤズィト2世即位を支えた忠臣

この解釈では、イシャクは1481年に首都を安定化させ、コルクト代理を通じてバヤズィトの即位を可能にした忠実な高官として理解される。

## Interpretation B: 首都危機を実務的に処理した媒介者

この解釈では、彼の重要性は個人的忠誠よりも、伝令、給与、儀礼、守備、王子代理、軍事者の接続を実務的に処理した点にある。

## Interpretation C: 必要な統合者から、独立した政治重心へ

この解釈では、1481年に必要だった彼の軍事者への影響力と家臣ネットワークが、危機後にはバヤズィトにとって慎重に扱うべき独立重心へ見えたと考える。

## Interpretation D: ワクフを通じて地域的な持続性を作った寄進者

この解釈では、イネギョル・イスタンブル・サロニカの寄進を、軍事・行政の経歴を都市・移動・教育・滞在者・家門記憶へ変換する長期的な制度として読む。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

イシャク・パシャの最大の課題は、

> バヤズィトを支持するか、ジェムを支持するか。

だけではなかったのかもしれない。

1481年の首都では、

- 兵士を何日待たせられるか
- 伝令が戻らない状態で、誰に命令を出せるか
- コルクトを置くことで、王朝の「顔」をどこまで保てるか
- 市場と街路の騒擾をどこまで抑えられるか
- 王子の到着前に、別の王朝中心が首都で成立するのを防げるか
- 即位後に、自らの軍事者・家臣への影響力をどこまで維持できるか
- 地方の寄進とワクフを通じて、危機後にも家門・収益・都市記憶をどう残せるか

が同時に問われていた。

この見方では、彼は単なる「忠臣」でも、単なる「権力者」でもない。

彼は、

> 王朝の空白を完全には埋められないまま、その空白が暴力と分裂へ変わる速度を遅らせ、特定の継承を行政的に可能にした媒介者

だった可能性がある。

ただし、その媒介は中立的ではない。

それはバヤズィトの即位を支え、ジェムの選択肢を狭める政治行為だった。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- イシャク・ビン・イブラヒムと、同時代の他のイシャク・パシャを混同しない。
- 生年、教育、民族的出自、デヴシルメかどうかを確定しない。
- 1450年代のすべての遠征や軍事指揮を、イシャク・ビン・イブラヒムへ帰属させない。
- 1460年代・1470年代の大宰相歴を、確定した年表として扱わない。
- アクサライ住民移送を、彼一人の命令・実施・意図として扱わない。
- 1481年の行動を、完全な中立行政または単純な私的派閥行動に還元しない。
- コルクト代理を独立した即位・統治として扱わない。
- ワクフを、純粋な慈善またはすべての人への平等な利益として扱わない。
- 建築・碑文・墓廟から、彼の私的内面や地域社会全体の受容を直接推測しない。
- 構造的説明を、暴動、殺害、強制移送、課税、財産介入、不平等、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
