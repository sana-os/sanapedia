# ムラト2世

> **研究状態:** Provisional  
> **中心問題:** 空位時代後に再接続されたオスマン家は、ムラト2世の時代に、王朝継承、軍事者、都市、港、道路、外交、宗教的寄進を、どこまで再び反復可能な統治関係へ組み直せたのか。  
>
> **注意:** このページはムラト2世を、メフメト2世のための前段階としてのみ扱わない。1421年の即位危機、東ローマ帝国（後世の通称：ビザンツ帝国）との関係、バルカンの戦争と休戦、1444年の譲位、1446年の復位、都市・ワクフの整備を、彼自身の統治問題として扱う。

# Human Overview

ムラト2世は、メフメト1世の子であり、1421年から1444年、そして1446年から1451年までオスマン家を統治した人物である。

彼が即位した時、オスマン家は空位時代を経て再び一つの王朝として行動していた。

しかし、再統一は安定の完成ではなかった。

ムラトは即位直後から、

- ムスタファ・チェレビをめぐる王朝的請求
- 弟クチュク・ムスタファをめぐる競争
- 東ローマ帝国との外交と軍事
- アナトリア諸侯家との関係
- ヴェネツィアと海峡・港をめぐる緊張
- セルビア、ワラキア、ハンガリー、アルバニア、モレアの政治
- 都市・市場・城砦・道路・軍事者の維持
- 若いメフメト2世への譲位と、その後の意思決定の空白

を同時に扱う必要があった。

1422年のコンスタンティノープル包囲、1430年のテッサロニキ掌握、1444年の譲位とヴァルナ、1446年のブチュクテペ事件、1448年の第二次コソヴォは、別々の軍事事件ではない。

それぞれは、

> 王朝の正統性、軍事者の報酬、都市と港の安全、外交上の承認、地方支配者の協力、そして誰が最終決定を下すのか

をめぐる問題だった。

このページではムラト2世を、

> 空位時代後の王朝が、再び分裂しないために、軍事・都市・外交・軍事者・寄進を接続し続けようとした統治者

として扱う。

# Why This Person Matters

ムラト2世を通じて、次の問いを考えることができる。

- 内戦を終えた王朝は、なぜその後も継承危機に脆弱なのか。
- 王位請求者をめぐる争いは、なぜ都市、港、地方軍事者、東ローマ、アナトリア諸侯家を巻き込むのか。
- 戦争と休戦は、単純に反対の政策なのか。それとも補給・都市・軍事費・外交を調整する異なる手段なのか。
- 若い後継者を即位させるとき、誰が軍事命令、給与、外交、裁判、都市秩序を実際に動かすのか。
- イェニチェリは、単に命令を受ける軍事者ではなく、統治条件を交渉する主体だったのか。
- 大規模モスク、複合施設、橋、イマレット、ワクフは、都市・交通・宗教・収益・王朝記憶をどう接続したのか。
- 後世はなぜムラト2世を「敬虔で節度ある支配者」または「征服者の父」として記憶しやすかったのか。

# Source Problem

## 「1453年の前史」へ還元されやすい統治

ムラト2世は、メフメト2世の父として知られる。

そのため、後世の叙述では、彼の時代が1453年の前段階として整理されやすい。

しかし、この枠組みだけでは、ムラト自身が直面した問題が見えにくくなる。

- 1421年の即位時における王朝内外の競争
- 1422年の包囲と、王位請求者支援をめぐる東ローマとの関係
- テッサロニキ、ガリポリ、海峡、港をめぐるヴェネツィアとの緊張
- セルビア、ワラキア、ハンガリーとの戦争・休戦・貢納・婚姻
- 1444年の譲位
- 1446年のイェニチェリ関与の危機
- 第二次コソヴォ後に続く地域差の大きい統治

これらは、息子の征服を準備するためだけに起きた出来事ではない。

## 記録の距離

ムラト2世期には、オスマン年代記だけでなく、東ローマ側叙述、ヴェネツィア資料、セルビア・ハンガリー・ワラキア関係資料、建築、ワクフ、貨幣が残る。

ただし、それぞれは異なる関心を持つ。

- オスマン年代記は王朝的連続性を強調しやすい。
- 東ローマ側の記録は都市防衛と王朝的生存の視点を持つ。
- ヴェネツィア資料は海上安全・港・通商を重視する。
- バルカン側の記録は、貢納、軍事、婚姻、地域的自律をめぐる関心を持つ。
- 建築とワクフは、寄進と都市基盤を示すが、寄進者の内面を直接証明しない。

# Historical Context

## Before: 再統一された王朝の不安定さ

メフメト1世は、1402年後の王朝内戦からオスマン家を再びつなぎ直した。

しかし、1421年にムラトが即位したとき、その接続は固定されたものではなかった。

アナトリアには、

- 旧諸侯家
- 地方軍事者
- 土地・収益をめぐる既存権利
- 都市と市場
- 宗教施設
- トルクメン・遊牧的集団
- 王朝内の別の請求者

が存在していた。

ルメリには、

- 東ローマ帝国
- ヴェネツィア
- セルビア、ワラキア、ハンガリー
- 港、海峡、城砦、道路
- 軍事者、都市、農村
- 貢納、婚姻、休戦、軍事協力のネットワーク

が重なっていた。

再統一とは、これらが一度に同じ方向へ動くことではなかった。

## During: 王位請求者と都市・海峡の政治

ムスタファ・チェレビをめぐる危機は、単なる兄弟・叔父の争いではない。

そこには、

- 東ローマが王位請求者を外交資源として扱うこと
- ガリポリ・海峡・船の統制
- ルメリ軍事者の支持が変わりうること
- アナトリア諸侯家が王朝内競争を利用しうること
- 都市と城砦が誰を正統な統治者として認めるか

が関わっていた。

1422年のコンスタンティノープル包囲は、軍事行動であると同時に、こうした請求者支援の政治的条件を変えようとする行為でもあった。

## After: 譲位と復位は何を露出させたか

1444年の譲位は、王朝が将来の継承を準備する試みとして理解できる。

しかし、若いメフメト2世が即位すると、次の問いがただちに現れた。

- 宰相は誰の命令を最終命令と考えるのか。
- イェニチェリは誰に給与・地位・軍事的保護を求めるのか。
- ルメリ軍事者は誰が遠征を率いると信頼するのか。
- 東ローマ、ハンガリー、ヴェネツィア、セルビアは誰を交渉相手と見るのか。
- 都市は誰の名で税・裁判・防衛を受けるのか。

ヴァルナとブチュクテペは、単にムラトが戻った出来事ではない。

それは、王朝的な正統性と、実際の意思決定・軍事指揮・給与・外交が、まだ安全に受け渡されていなかったことを示す。

# Layer A — 生存・物質的安定性層

## 軍事は都市と補給の問題でもある

ムラト2世の戦争は、戦場だけで完結しない。

軍事行動には、

- 兵士と交代要員
- 馬、飼料、水、食糧
- 銀、貨幣、給与、戦利品
- 城砦、道路、橋、渡河地点
- 港、船、海峡
- 農村からの供給
- 都市市場、職人、倉庫
- 地域軍事者と地方支配者の協力
- 使節、情報、休戦、贈答

が必要だった。

複数戦線に対応するには、戦争と休戦を、互いに反対の政策ではなく、資源と時間を管理する異なる手段として使い分ける必要があった。

## テッサロニキと海峡

1430年のテッサロニキ掌握は、単に都市の軍事的掌握ではない。

都市には、

- 港
- 市場
- 海上交通
- 周辺農村
- ヴェネツィアとの通商・軍事関係
- エーゲ海とルメリの連結

が関わっていた。

同様に、ガリポリと海峡は、アナトリアとルメリを結ぶ軍事・通商・外交の接点だった。

# Layer B — 意味・認識層

## 「秩序」の意味は一つではない

ムラト2世の統治は、各集団に同じ意味を持たなかった。

| 主体 | 「王朝秩序」が意味した可能性 |
|---|---|
| ムラトと宮廷 | 王位請求の抑制、軍事指揮、都市・収益・外交の継続 |
| イェニチェリ | 給与、貨幣、地位、軍事機会、最終的な命令者 |
| ルメリ軍事者 | ティマール、戦利品、地方的影響力、城砦・道路への接近 |
| アナトリア諸侯家 | 自立、服属、旧領、貢納、軍事同盟、王朝内競争の利用 |
| 都市住民 | 市場、食糧、税、道路、守備、軍事略奪の抑制 |
| 東ローマ側 | コンスタンティノープル、海峡、王位請求者、貢納、外交的余地 |
| セルビア・ワラキア | 城砦、婚姻、ハンガリーとオスマンの間の選択、貢納 |
| 後世のオスマン記憶 | 敬虔な支配者、安定の回復、征服者の父 |

## 敬虔さ・ガーズィー像・王朝的記憶

ムラト2世は後世の記録で、敬虔で節度ある支配者、またガーズィー的な軍事君主として描かれる。

この像は、単に真実か虚偽かの二択では扱えない。

称号、寄進、建築、戦争、儀礼、墓所、年代記、学者・宗教者との関係は、統治者の像をつくる。

重要なのは、

> なぜムラトの統治を、節度と敬虔さを持つ王朝秩序として記憶する必要があったのか。

という問いである。

# Layer C — 制度・運用層

## 宰相・軍事者・地方社会をつなぐ仕事

ムラト2世期の統治は、後の時代の完成された制度をそのまま持っていたわけではない。

しかし、以下の問題はすでに重要だった。

- 土地・収益・軍役・官職の配分
- 軍事者への報酬
- 都市収入、関税、農村税の把握
- 城砦、道路、港、海峡の維持
- 裁判・書記・ワクフ・宗教施設
- 王子、王位請求者、王朝成員の管理
- 条約と休戦の実際の履行
- アナトリアとルメリの異なる地域条件

宰相、書記、カーディ、地方軍事者、都市有力者、宗教者、使節は、単にスルタンの命令を待つ人々ではなかった。

彼らは、命令を軍事・税・都市・外交・地域社会の実務へ翻訳する媒介者だった。

## ブチュクテペ事件

ブチュクテペ事件は、イェニチェリを単なる反乱者として扱えないことを示す。

原因を単一に確定することはできないが、少なくとも次の条件が重なった可能性がある。

- 若いメフメト2世の第一次統治
- ムラト2世の退位後も残る軍事的権威
- ヴァルナ後の軍事・外交の緊張
- 給与、貨幣、物価、戦利品をめぐる不満
- 宰相・宮廷集団の競争
- 軍事者が最終命令者を見極められない不安

この出来事は、軍事者が統治の資源であると同時に、統治の条件を交渉する政治的主体であったことを示す。

## 都市・ワクフ・交通

ブルサのムラディエ複合体、エディルネのムラディエ、ウチュ・シェレフェリ複合体、エルゲネ橋周辺の寄進は、宗教建築だけではない。

それらは、

- 礼拝
- 教育
- 食事
- 滞在者・旅行者への支援
- 水と衛生
- 交通
- 市場
- 収益を生む財産
- 職人と建設資材
- 都市の王朝記憶

を結びつける。

寄進は、統治を都市の日常へ接続する制度でもあった。

# Competing Interpretations

## Interpretation A: 空位時代後の安定化を担った軍事君主

この解釈では、ムラト2世は、即位危機を処理し、テッサロニキ、ヴァルナ、第二次コソヴォを通じて、オスマン家の軍事的・外交的地位を保った人物として理解される。

## Interpretation B: 戦争と調整を組み合わせた統治者

この解釈では、ムラトの重要性は軍事行動だけでなく、休戦、貢納、婚姻、使節、地方有力者との調整、都市寄進にある。

この視点では、統治の強さは一方的な命令ではなく、複数の関係を崩壊させずに保つ能力でもある。

## Interpretation C: 譲位と復位が制度的な脆さを露出させた

この解釈では、1444年の譲位と1446年の復位は、王朝に柔軟性があったことを示す一方、若い君主、宰相、イェニチェリ、地方軍事者、外部勢力の間で最終決定権が不安定だったことを示す。

## Interpretation D: 1453年中心の記憶がムラトを単純化した

この解釈では、後世の「征服者メフメト」の物語が強いため、ムラトが単なる父・準備者として縮小されやすいことを重視する。

この視点では、ムラト自身の継承危機、都市整備、外交、軍事者との関係を、独立した歴史問題として扱う。

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

ムラト2世の最大の課題は、

> どこまで領域を広げられるか。

だけではなかったのかもしれない。

むしろ、

- 空位時代を経験した軍事者や都市が、再び王朝分裂を予想しないようにできるか
- 王位請求者を支える外部勢力に、介入の余地をどこまで与えないか
- アナトリアとルメリの軍事・都市・収益を、同じ王朝のもとで動かし続けられるか
- 若い後継者へ権限を渡すとき、軍事者と宰相が「命令の空白」を感じないようにできるか
- 港、海峡、城砦、道路、市場を、軍事と通商の両方に使える状態で保てるか
- 都市への寄進を通じて、王朝の継続を日常生活の中でどのように可視化できるか

が同時に問われていた。

ムラトの1444年譲位と1446年復位は、

> 父が息子の王位を取り返した。

という出来事だけではなく、

> 統治の役割が安全に引き渡されていないとき、軍事者・宰相・都市・外部勢力がどこに最終決定者を探すのか。

を示した可能性がある。

この仮説は、ムラト2世を近代的制度改革者として描くものではない。

また、彼の統治がすべての人に安全や利益を与えたと主張するものでもない。

戦争、徴税、軍役、処罰、強制移動、地域社会への圧力は、同じ統治の中に存在していた。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- ムラト2世の母、教育、若年期のすべての詳細が確定しているとは主張しない。
- 1421年の即位が、直ちにアナトリアとルメリの全地域で均一に受け入れられたとは主張しない。
- ムスタファ・チェレビやクチュク・ムスタファをめぐる危機を、単なる個人的野心だけで説明しない。
- 1422年のコンスタンティノープル包囲を、1453年の征服の直前段階として扱わない。
- テッサロニキ掌握を、軍事的出来事だけで説明しない。
- 1444年の譲位を、宗教的隠遁、疲労、王朝戦略、家族的感情、失敗のいずれか一つに還元しない。
- ブチュクテペ事件を、貨幣改鋳、給与、宰相の策動、イェニチェリの不満のいずれか一つだけで説明しない。
- イェニチェリを単なる反乱者、または近代的政治組織として扱わない。
- ウチュ・シェレフェリ複合体やムラディエ複合体を、単なる中央集権の宣伝装置として扱わない。
- 第二次コソヴォの後に、バルカン全体が均一なオスマン支配へ入ったと主張しない。
- 後世の「敬虔なムラト」像を、私的内面の完全な記録として扱わない。
- 構造的説明を、戦争、包囲、捕虜化、徴発、課税、処罰、宗教的圧力、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。

- Georgios Sphrantzes, *Chronicon Minus*, ed. Vasile Grecu. Bucharest, 1966.
