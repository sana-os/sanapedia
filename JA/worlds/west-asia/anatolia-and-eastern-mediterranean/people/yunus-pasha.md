# ユヌス・パシャ

> **研究状態:** Provisional  
> **中心問題:** 1517年、オスマン政権は軍事的にエジプトを掌握した直後、どのように都市、税、旧軍事者、法、港、紅海、地域社会を統治へ接続しようとしたのか。ユヌス・パシャは、その移行期に何を担い、なぜ短期間で失脚したのか。  
> **注意:** このページは、ユヌス・パシャを単なる「腐敗した高官」または「セリム1世の犠牲者」として固定しない。彼を、征服直後の高負荷な統治環境で、軍事・財政・行政・都市秩序を同時に扱わされた実務者として読む。

# Human Overview

ユヌス・パシャは、セリム1世のエジプト遠征の最終局面で大宰相となり、短期間ながらエジプト統治にも関わったオスマン高官である。

彼の生涯について、出生地、家族、初期教育、宮廷への編入経路は十分には確定していない。

後世の概説では、デヴシルメ出身、イェニチェリ系の軍人、あるいは宮廷軍事官僚として説明されることがある。

しかし、公開ページでは、その出自を一つの民族・宗教・徴募経路へ固定しない。

比較的追えるのは、1510年代の後半である。

- アナトリア方面での軍事・行政経験
- セリム1世期の軍事組織との接続
- 1516年から1517年のマムルーク戦争
- リダニヤ後の大宰相就任
- カイロとエジプトの統治をめぐる短期的な責任
- ハイル・ベイへの総督交代
- 1517年9月の失脚と処刑

昔の人たちってどうしてそんな行動をとったんだろう？

ユヌス・パシャの場合、この問いは「なぜ汚職をしたのか」だけでは足りない。

むしろ、

> 征服直後で、行政知識・地域協力・安定した税収・治安・情報が不足するなか、中央から大きな成果を求められた高官は、どのような選択肢を持ちえたのか。

を考える必要がある。

# Source Problem

## 「腐敗した総督」という説明だけでは見えないもの

ユヌス・パシャの失脚は、しばしば次のように説明される。

- カイロで不正行為を行った
- 総督職をハイル・ベイへ移されたことに怒った
- ハイル・ベイを侮辱した
- セリム1世が即座に処刑した

この叙述には、一定の史料的根拠がある。

しかし、それだけでは1517年のエジプト統治の難しさが消えてしまう。

征服直後のエジプトでは、

- カイロの治安
- 旧マムルーク軍事者への対応
- ベドウィンや地方勢力との関係
- ナイル流域の農業と税
- 都市市場と食糧
- 紅海・地中海・隊商路
- 旧来の法学者・裁判・宗教施設
- 軍の給与と帰還希望
- 中央への報告と送金

が同時に動いていた。

大宰相とエジプト統治者の責任が一人へ集中すると、成功は中央へ帰属しやすく、失敗は個人へ集中しやすい。

そのため、このページでは、ユヌス・パシャの個人的責任を消さずに、彼を取り巻く統治環境も可視化する。

# Historical Context

## Before: セリム1世の大遠征

1516年から1517年のオスマン・マムルーク戦争は、単なる領土拡大ではなかった。

シリア、エジプト、ヒジャーズ、紅海、東地中海、隊商路、都市市場、農村税、宗教的正統性が重なる空間を、オスマン政権が新たに扱うことになった。

軍事的な勝利は比較的短期間で生じた。

しかし、統治を持続させるには、別の時間が必要だった。

- 誰が税を記録するのか
- 誰が農村と水利を把握するのか
- 誰がカイロの市場と治安を維持するのか
- 誰が旧軍事者を武装解除し、雇用し、監視するのか
- 誰が法学者・裁判・寄進を扱うのか
- 誰が紅海・地中海・港・隊商路を守るのか
- 誰が中央へ正確な情報を届けるのか

ユヌス・パシャは、この「征服後に始まる統治」の初期段階に置かれた。

## During: エジプトの統治を急いで組み替える

征服直後の統治では、中央が早く成果を求めるほど、現地の複雑さを見落としやすい。

エジプトには、ナイル流域の農業、都市市場、軍事者、宗教施設、裁判、旧官僚、ベドウィン集団、紅海・地中海の交易があった。

これらは、単一の中央命令だけでは動かない。

ユヌス・パシャの短い統治は、征服軍の論理を日常統治へそのまま移すことの限界を示す。

軍事的に都市を掌握できても、

> 税、食糧、輸送、法、地域協力、情報が接続されなければ、統治は安定しない。

## After: 包摂と再配置

ユヌス・パシャの後、ハイル・ベイがエジプト統治に深く関わったことは、オスマン政権が旧マムルーク系の知識・人脈・地域的接続を無視できなかったことを示す。

これは、オスマン統治が単純に旧制度を破壊し、新制度を一方的に導入したという意味ではない。

むしろ、

> 軍事的勝利の後、旧い人材・市場・行政知識・地域社会を、選別しながら新しい統治へ組み込む必要があった。

ということを示している。

# Layer B — Narrative

## 征服者の語りと都市の記憶

セリム1世期のシリア・エジプト征服は、オスマン王朝にとって軍事的成功と宗教的正統性を結びつける機会になった。

しかし、カイロやエジプトの人々にとっては、征服は別の意味を持ちえた。

- 都市の戦闘
- 財産の不安
- 旧軍事者の失職
- 市場や税の変化
- 職人・学者・書物・人材の移動
- 新しい役人と軍隊の到来
- 法と宗教施設への不確実性

同じ出来事が、中央には「統合」に見え、地域には「急な断絶」に見えることがある。

## 「征服者の報酬」という感覚

ユヌス・パシャがハイル・ベイの起用をどう受け止めたかについて、後世の史料は侮辱的な発言を伝える。

その文言と場面の細部は慎重に扱う必要がある。

ただし、そこには、

- 征服に参加した軍事者の期待
- 新領域の役職・収益を誰が得るか
- 旧支配層を取り込むことへの不信
- 中央が何を「忠誠」と見なすか

という問題が重なっていた可能性がある。

# Layer C — Institution

## 大宰相・総督・軍事責任の集中

ユヌス・パシャの危険は、単に権力が大きかったことではない。

複数の異なる役割が、短期間に一つの人物へ集中したことにあった。

- 大宰相として中央の命令を実行する
- 軍事指揮を維持する
- 新征服領の統治を始める
- カイロの治安を扱う
- 税・送金・収益を整理する
- 旧マムルーク人材を監視・利用・排除する
- セリム1世へ成果を報告する

このような役割集中では、問題が起きたとき、原因が複数であっても責任は一人へ集まりやすい。

## ハイル・ベイをどう読むか

ハイル・ベイは、旧マムルーク世界とオスマン統治のあいだをつなぐ人物として重要である。

彼の任用を、単に「征服者が裏切り者を褒美として登用した」と見るだけでは不十分である。

彼は、

- エジプトの軍事者
- 都市の有力者
- 地方の情報
- 旧統治の人材
- 行政慣行
- 地域的な信頼と不信

に接続できる可能性を持っていた。

そのため、彼の起用は、中央の直接統治だけでは足りないという認識の表れとして読むことができる。

ただし、この包摂は平等でも穏やかでもない。

旧マムルーク系の人々、都市民、農村、ベドウィン集団が同じ利益を得たわけではない。

# Role System Model

| Role | 主な担い手 | 1517年エジプトで見える問い |
|---|---|---|
| Decider | セリム1世 | 征服後に何を優先し、誰を任命し、どの負荷を許容するか |
| Architect | 大宰相、宰相、書記、財政官、法学者 | 新領域の税・軍事・裁判・行政をどう組み立てるか |
| Integrator | ハイル・ベイ、法学者、都市有力者、地方仲介者 | 中央と地域社会を誰が接続するか |
| Executor | ユヌス・パシャ、守備隊、軍事者、徴税者、地方官 | 命令、軍事、徴税、治安を誰が実行するか |
| Observer | 使者、書記、商人、法学者、地方官、密偵 | カイロと地方の状況を中央はどこまで知れたか |
| Auditor | 都市民、軍事者、旧マムルーク人材、地域社会、中央財政官 | 統治の負荷と不正を誰が可視化したか |

## RSM上の中心問題

ユヌス・パシャは、1517年のエジプトで強いExecutorだった可能性がある。

しかし、新征服領ではExecutorだけでは足りない。

地域社会、旧制度、法、都市、市場、農村、港をつなぐIntegratorが必要になる。

この視点から見ると、彼の失脚は、

> 実行の責任を集めすぎた人物が、統合に必要な地域的接続を十分に持てなかったときに起きる危機

として読むことができる。

# GMM: 統治能力の観察

| Layer | Demand | Supply | 観察されるギャップ |
|---|---|---|---|
| A — Survival | 治安、軍の給与、食糧、港、農業、交通、都市秩序 | 軍事者、税、ナイル流域、都市市場、港、地域協力 | 征服直後の混乱、補給、財政、治安の同時不足 |
| B — Narrative | 新しい統治の正統性、宗教的安心、都市の尊厳、征服者の威信 | 王朝、儀礼、法、称号、宗教施設、軍事勝利 | 中央の統合物語と現地の喪失経験の差 |
| C — Institution | 税、裁判、軍役、官職、地方行政、送金、港湾統治 | 宰相、書記、法学者、旧人材、地域仲介者、文書 | 中央の制度移植速度と現地適応速度の差 |

## GMM上の読み方

1517年のエジプトは、軍事的に掌握された瞬間に、制度的にも安定した地域になったわけではない。

軍事勝利の速度に対して、

- 都市社会が新しい統治を理解する速度
- 地方の税・水利・農業を把握する速度
- 旧人材を選別し、再雇用し、監視する速度
- 法と行政を調整する速度

が追いつかない可能性があった。

ユヌス・パシャは、この時間差が最も大きい時点で責任を引き受けた人物として見ることができる。

# Competing Interpretations

## Interpretation A: 不正行為によって失脚した高官

この見方では、ユヌス・パシャはカイロでの不正行為、強圧的な徴収、ハイル・ベイへの侮辱によってセリム1世の信頼を失い、処刑された人物として理解される。

## Interpretation B: 征服直後の過大な役割を負わされた実行者

この見方では、彼は大宰相、軍事指揮、エジプト統治を短期間に集中して担い、行政知識と地域協力が不足するなかで失敗した人物として理解される。

## Interpretation C: 現地統合へ転換する前に外れた人物

この見方では、ハイル・ベイの登用は、中央が旧マムルーク系の人材を含む間接的・混成的統治へ移る必要を認識した転換点であり、ユヌス・パシャはその転換に適応できなかった人物として読まれる。

## Interpretation D: セリム1世期の責任集中を示す人物

この見方では、ユヌス・パシャの処刑は、セリム1世の強い統治が、征服後の混乱や制度的失敗を高官個人へ集中させる政治構造を持っていたことを示す。

---

# 【ここからはサナの推測（歴史ミステリー）なんだけど……】

ユヌス・パシャは、エジプトを「征服した後に統治する」という二つの仕事の差を、最も激しく引き受けた人物だったのかもしれない。

征服では、速い決断、兵士、火力、行軍、恐怖、命令が大きな力になる。

しかし統治では、

- 税を誰が理解するか
- 市場を誰が落ち着かせるか
- 旧い人材を誰が使うか
- 地域の不満を誰が聞くか
- 中央が何を知らないか
- どこで妥協し、どこで強制するか

が重要になる。

ユヌス・パシャは、征服期のExecutorとしては有能だった可能性がある。

しかし、1517年のエジプトには、征服者の論理だけでなく、地域の知識と長期的な接続を扱うIntegratorが必要だった。

彼の処刑は個人の責任を消さない。

ただし同時に、

> 巨大な新領域を急いで統治へ組み込もうとした帝国が、最初に置いた実行者へ多すぎる負荷を集中させた。

という構造も見える。

# What This Page Does Not Claim

- ユヌス・パシャの出生地、民族、デヴシルメ経歴を確定しない。
- 彼を単なる腐敗した人物、または完全に無実の犠牲者として扱わない。
- カイロでの不正行為を、制度的圧力だけで免罪しない。
- 不正行為を、個人の性格だけで説明しない。
- 1517年のエジプト統治を、完全な直接統治または完全な旧制度維持のどちらかとして扱わない。
- 旧マムルーク人材の登用を、平等な和解として扱わない。
- ハイル・ベイの任用を、民族・宗教・裏切りだけで説明しない。
- セリム1世の処刑判断を、一つの侮辱発言だけで説明しない。
- 征服後の統治を、軍事的勝利の自動的な結果として扱わない。
- 構造的説明を、略奪、徴税、処刑、都市暴力、強制移動、不平等の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
