# リュステム・パシャ

> **研究状態:** Provisional  
> **中心問題:** スレイマン1世後半の帝国が、戦費、現金、任官、ハプスブルク外交、サファヴィー国境、王子問題、都市ワクフを同時に扱うなかで、リュステム・パシャはなぜ二度大宰相となり、なぜ強い反発と悪評の対象になったのか。  
>
> **注意:** このページはリュステムを、帝国を一人で変えた財政改革者とも、単なる陰謀家とも扱わない。彼は、広がった帝国の財政・軍事・宮廷・地方統治を接続する役割を担い、その接続が新たな負担と対立を生んだ人物として扱う。

# Human Overview

リュステム・パシャは、16世紀前半に宮廷で上昇し、1544年から1553年、そして1555年から1561年にかけて、二度にわたりオスマン帝国の大宰相を務めた。

彼はモハーチ遠征にシラフダルとして参加し、1526年には大ミラフールに任命された。その後、複数の地方任命を経て、1538年にアナトリア・ベイレルベイ、1539年末までに宰相となり、1541年には第二宰相へ進んだ。[^afyoncu-rustem]

1539年12月、リュステムはスレイマン1世の娘ミフリマー・スルタンと婚姻した。

この婚姻は、彼を王朝のダマトとして位置づけ、宮廷における政治的近接性を大きく変えた。[^afyoncu-rustem]

1544年12月、リュステムは大宰相へ就任した。

その第一期には、1545年の休戦、1547年のハプスブルクとの合意、1548年の対サファヴィー遠征、現金収益・任官・徴税請負をめぐる財政運用、拡張した帝国の行政・軍事の維持が重なった。[^afyoncu-rustem]

1547年のハプスブルクとの合意では、フェルディナント側がハンガリーの一部をめぐり年額三万金の支払いを受け入れたとされる。

ただし、これは単に「外交上の勝利」としてではなく、西方の戦費、国境維持、王位問題、財政の予測可能性を組み合わせる試みとして見る必要がある。[^afyoncu-rustem]

リュステム期にはイルティザームが広がった。

これは、ムカタア収入を現金化し、国家が軍隊、砦、行政、人事に必要とする流動資金を確保するのに役立った一方、地方の徴税負担と請負の問題を強めうる制度でもあった。[^afyoncu-rustem]

1553年、対サファヴィー遠征中にシェフザーデ・ムスタファが処刑された。

同時代・近接史料と後世の叙述の多くは、リュステムがこの事件に深く関与したと語る。

しかし、最終的な処刑を命じたのはスレイマンであり、リュステムの役割、ヒュッレム・スルタンの影響、軍事者や情報提供者の位置は一つの物語に固定できない。[^afyoncu-rustem]

ムスタファ処刑への反発は軍と社会に広がり、リュステムは1553年10月に罷免された。

しかし、彼は処刑されず、二年間ウスキュダルの邸宅に留まり、1555年9月に再び大宰相へ復帰した。[^afyoncu-rustem]

第二期にはジェルバ海戦の勝利、セリムとバヤズィトの王子競争、サファヴィー国境、対ハプスブルク関係が重なった。

リュステムは当初バヤズィトを支持したと記録されるが、1559年にバヤズィトが反乱状態となりイランへ逃れると、セリム側へ移った。[^afyoncu-rustem]

リュステムは1561年7月12日に死去した。

彼はイスタンブルのシェフザーデ・ジャーミイ墓域に埋葬され、残された巨大な財産、ワクフ、商業施設、モスク、学校、ハン、キャラバンサライは、彼の権力が財政・都市・慈善・交易の回路と結びついていたことを示す。[^afyoncu-rustem][^rustem_complex]

このページでは彼を、

> 現金、任官、地方収益、外交、王朝婚姻、軍事遠征、ワクフを接続し、拡張後の帝国の処理能力を高めようとした大宰相。その一方で、接続の負担と道徳的非難を強く引き受けた人物

として扱う。

# Why This Person Matters

リュステム・パシャを通じて、次の問いを考えることができる。

- 大宰相は、なぜ軍事指揮者であると同時に、現金・任官・帳簿・外交・都市施設を結ぶ設計者になったのか。
- 王朝との婚姻は、単なる私生活ではなく、どのように政治的近接性と生存可能性を変えたのか。
- イルティザームの拡大は、なぜ中央の現金収入を増やしうる一方で、地方社会への負担を増やしうるのか。
- 任官時の公的納付、カイズェ、贈答、賄賂を、なぜ単純に一つの「腐敗」として扱えないのか。
- ハプスブルクとの休戦・協定は、なぜ戦争の終結ではなく、国境維持と軍事財政の調整でもあったのか。
- ムスタファ処刑は、なぜ「ヒュッレムとリュステムの陰謀」という一つの物語だけで説明できないのか。
- 巨大な財産とワクフは、私的蓄財、政治的安全、都市商業、宗教的慈善をどう結びつけたのか。
- 後世の「黒い心」「守銭奴」「有能な国家運営者」という像は、どのような評価の衝突を残しているのか。

# Source Problem

## 出自と宮廷参入

リュステムの出自には、サラエヴォ近郊、クロアチア系、ボスニア系、セルビア系、アルバニア系など、複数の記録がある。

| 記録上の説明 | 注意点 |
|---|---|
| サラエヴォ近郊の村で生まれた | 比較的有力な伝承だが、出生地を完全には確定しない |
| 特定の民族・宗教共同体に属した | 後世の民族的分類を含み、固定しにくい |
| 奴隷・内廷教育を経て上昇した | 宮廷へ入る経路の細部には不明点がある |
| 若くしてスレイマンの目に留まった | 窓から飛び降りた逸話など、物語化の可能性がある |

このページでは、出自を能力・人格・政策を自動的に説明する鍵として使わない。

## 「幸運の虱」逸話

1539年の婚姻前、敵対者がリュステムをハンセン病患者だと中傷し、医師が衣服の虱を見つけたことで無病が証明された、という逸話が伝わる。

TDVは、この逸話を後代の政治的対立が生んだ可能性の高い話として注意している。[^afyoncu-rustem]

このため、婚姻はFactとして扱うが、虱の逸話はRecordとして扱う。

## 財政とイルティザーム

リュステム期にイルティザームは広がった。

ただし、

- イルティザームは彼以前から存在した
- 徴税請負の実態は州・税源・年次ごとに異なる
- 現金収入の増加と地方負担の増加は、同時に起こりうる
- 後世の批判は17世紀以降の状況を遡及している場合がある

ため、「彼が全てを創始し、直ちに帝国全土を変えた」とは扱わない。[^afyoncu-rustem]

## ムスタファ処刑

ムスタファ処刑は、リュステムの評価を決定づけた。

しかし、史料は次のように異なる層を持つ。

| 層 | 何が見えるか | 限界 |
|---|---|---|
| Fact | 1553年、ムスタファがスレイマンの命令で処刑され、リュステムが罷免された | 個々の助言・情報・意図を完全には示さない |
| Perception | 軍事者・民衆・詩人の間でリュステムへの怒りが高まった | 怒りが実際の因果関係を自動的に証明しない |
| Record | ヒュッレムとリュステムの共同策謀、偽情報、個人的敵意などの物語 | 後世の道徳的・政治的再構成を含む |

| ハプスブルク使節 | 誰が交渉を担うか、称号、ハンガリー、休戦、戦費 |
| サファヴィー側 | 国境、遠征、亡命王子、アゼルバイジャン・イラク、軍事圧力 |
| 後世の記録者 | 有能な宰相、蓄財家、ムスタファ事件の責任者、道徳的警告 |

### Record: 何が残っているか

| 記録・物証 | 何を示しうるか | 限界 |
|---|---|---|
| ルズナムチェ・任官帳簿 | 官職、給与、人事、制度的移動 | 私的動機や実際の現地運用を全面的には示さない |
| ムカタア・イルティザーム記録 | 現金収入、請負、税源、中央財政 | 農民・都市住民の経験を一律に示さない |
| ハプスブルク・ヴェネツィア使節報告 | 外交、儀礼、リュステムの印象、宮廷の力関係 | 噂、驚き、交渉戦略、偏見を含む |

| ワクフィエ・建築 | 財産、慈善、商業、都市空間、宗教施設 | 私的意図やすべての収益流を単独では示さない |
| 遺産目録・蔵書記録 | 財産、土地、奴隷、動物、書物、ワクフの規模 | 数量・分類・所有権の解釈に注意が必要 |

# Historical Context

## Before: 拡張後に必要になった現金と行政

セリム1世期の征服とスレイマン初期の連続遠征により、帝国は広い領域を維持する必要に直面した。

必要だったのは、戦場での勝利だけではない。

- イェニチェリなど常備軍への現金給与
- 砦・道路・港・艦隊の維持
- エジプト、ハンガリー、イラクなど遠隔州との通信
- 軍事輸送と食糧
- 任官・監査・帳簿
- 王子と王朝の安全
- 都市市場とワクフ収益

リュステムの上昇は、この需要の中で理解する必要がある。

## During: 財政、外交、王子問題の接続

リュステムの大宰相期には、財政と外交が切り離せなかった。

西方の休戦は、国境の軍事費と現金収入に関わった。

徴税請負の拡大は、中央の資金需要と地方の負担を結びつけた。

ムスタファ処刑は、王子継承だけでなく、軍事者の忠誠、宰相への信頼、宮廷情報、対サファヴィー遠征を巻き込んだ。

## After: 罷免、復帰、評価の分裂

1553年、リュステムは罷免された。

しかし、二年後には復帰した。

このことは、宮廷近接性と王朝婚姻が、官職喪失後も政治的資源となりえたことを示す。

彼の死後に残ったのは、巨大な財産、都市施設、ワクフ、財政的悪評、ムスタファ事件の記憶だった。

# Layer A — 生存・物質的安定性層

## 現金、軍、交通、都市

リュステム期の帝国運用には、次の資源が必要だった。

- 現金給与
- 穀物・飼料・輸送
- 火薬・砲・兵器
- 砦・港・艦隊
- 税・関税・ムカタア
- 書記・帳簿・監査
- 遠征路・橋・市場・宿営
- 都市の商業施設
- ワクフ収益
- 宮廷と地方を結ぶ使節・命令・人事

## RBM: 資源需給バランスモデル

| Function | Demand | Supply | Main Bottleneck |
|---|---|---|---|
| 常備軍と遠征 | 現金、食糧、馬、砲、弾薬、道路、船 | 国庫、ムカタア、税、都市市場、後方州 | 戦費、距離、季節、現金不足 |
| 中央財政 | 予測可能な現金、帳簿、監査、人員 | イルティザーム、関税、州収益、任官納付 | 地方負担、不正、収益予測、反発 |
| ハプスブルク国境 | 砦、守備隊、外交、補給、休戦 | 軍、国境州、協定、年額支払い | ハンガリー王位、国境要塞、戦費 |
| サファヴィー国境 | 軍、補給、山地移動、情報、地方協力 | 東部州、城砦、軍、地方収益 | 長距離、焦土化、季節、情報差 |
| ワクフ・都市施設 | 店舗、倉庫、ハン、ハマム、賃料、管理者 | 私財、都市商業、ワクフ制度 | 維持費、管理、収益の安定、都市変動 |

# Layer B — 意味・認識層

## 「有能な宰相」と「黒い心」

リュステムは同時代・後世で対照的に描かれた。

| 像 | 何を強調するか | 注意点 |
|---|---|---|
| 有能な国家運営者 | 節約、帳簿、外交、財政、遠征運用 | 政策の負担や対立を消してしまう |
| 蓄財家 | 巨大な財産、任官金、ワクフ、商業施設 | 公的収入・私財・ワクフの境界を単純化しやすい |
| ダマト | ミフリマーとの婚姻、王朝近接性、政治的保護 | 婚姻を単なる陰謀の道具にしない |
| ムスタファの敵 | 1553年の処刑、軍内反発、哀歌 | 最終決定者であるスレイマンの役割を消してしまう |
| 幸運の虱 | 婚姻前の中傷と逆転 | 後世の政治的物語の可能性が高い |

## 財政の意味

中央にとって現金収入は、軍、砦、艦隊、任官、外交を動かす条件だった。

地方社会にとっては、同じ制度が、

- 税率
- 徴収者
- 支払時期
- 収穫不良時の負担
- 訴訟
- 移動
- 借金
- 市場価格

をめぐる日常的な圧力として現れた可能性がある。

そのため、財政の合理化を「効率化」とだけ呼ばない。

# Layer C — 制度・運用層

## イルティザーム、ムカタア、任官

リュステム期に重要なのは、制度が人物の意思だけで動いていないことだ。

| 制度・運用 | 何が問われたか |
|---|---|
| イルティザーム | 現金をどの速度で中央へ集め、徴税リスクを誰が負うか |
| ムカタア | 港・市場・塩・鉱山・農地などの収益をどう管理するか |
| 任官納付・カイズェ | 公的納付、贈答、不正をどこで区別し、どう記録するか |
| ルズナムチェ | 給与・収支・人事をどのように可視化するか |
| ワクフ | 商業施設の収益を、宗教・教育・福祉・都市維持へどうつなぐか |
| 大宰相職 | スルタンの委任を、遠征・外交・財政・任官へどう翻訳するか |

## ワクフは「慈善」だけではない

リュステムのワクフは、モスクや学校だけでなく、商店、ハン、キャラバンサライ、ハマム、倉庫、道路・交通の結節点と結びついていた。

そのためワクフは、

> 私財、都市商業、宗教的正統性、公共サービス、長期収益、政治的記憶

を結ぶ制度として見る必要がある。

# Role System Model

| 役割 | 主な主体 | リュステム期に見える問い |
|---|---|---|
| 決定者 | スレイマン1世 | 最終的に戦争、任官、王子処刑、休戦を誰が決定するか |
| 設計者 | リュステム、大宰相府、財務官、書記、法学者 | 現金、任官、遠征、外交、地方統治をどう接続するか |
| 統合者 | 州知事、徴税請負人、軍事者、商人、ワクフ管理者 | 首都、国境、都市、市場、地方収益を誰がつなぐか |
| 実行者 | 書記、徴税者、兵士、砲兵、船員、建築者、職人 | 帳簿、徴税、輸送、戦闘、施設維持を誰が担うか |
| 観察者 | 農民、都市住民、商人、軍事者、使節、詩人 | 政策を保護、負担、腐敗、機会のどれとして経験したか |
| 監査者 | スルタン、宰相、法学者、宮廷、軍、地方社会 | 現金、権限、任官、税、王子問題を誰が評価するか |

## RSM上の中心問題

リュステム・パシャの中心問題は、

> 彼がどれほど富を持っていたか。

だけではない。

むしろ、

> 大宰相職が、現金・帳簿・任官・外交・遠征・王朝近接性を一つに接続したとき、誰がその運用を監査し、地方社会の負担をどこで可視化できるのか。

である。

| Layer | Demand | Supply | Observed Gap |
|---|---|---|---|
| A — 生存・物質的安定性層 | 現金、軍、砦、港、食糧、輸送 | 税、ムカタア、請負、都市市場、ワクフ | 戦費、地方負担、現金化の圧力 |
| B — 意味・認識層 | 王朝正統性、宰相への信頼、王子の安全、宗教的慈善 | 婚姻、儀礼、称号、ワクフ、年代記、詩 | ムスタファ事件、悪評、派閥物語 |
| C — 制度・運用層 | 任官、帳簿、監査、徴税、休戦、州統治 | 大宰相府、財務、書記、法、地方官 | 権限集中、情報差、地方差、監査の限界 |

## GMM上の読み方

リュステム期は、単なる「中央集権化の完成」とは言い切れない。

より慎重には、

> 拡大した帝国の戦費と行政需要に対して、現金・記録・任官・請負・外交をより密に接続しようとした時期

と読むことができる。

その接続は処理能力を高めた可能性がある一方、地方負担、任官への不信、王子問題、宮廷の反発を増幅させた可能性もある。

# Competing Interpretations

## Interpretation A: 財政的・行政的な再編者

この解釈は、現金収益、ムカタア、イルティザーム、帳簿、ハプスブルク外交を重視する。

リュステムを、遠征と常備軍を支えるために財政の接続を強めた大宰相として読む。

## Interpretation B: 王朝婚姻に支えられた近接性の政治家

この解釈は、ミフリマーとの婚姻、ヒュッレムとの関係、罷免後の復帰を重視する。

ここでは、宮廷への近接性そのものが政治資源だったと考える。

## Interpretation C: 地方負担を増やした徴税体制の象徴

この解釈は、イルティザーム、任官納付、地方の苦情、後世の批判を重視する。

ただし、制度全体の長期的変化をリュステム一人に帰属させない。

## Interpretation D: ムスタファ事件によって悪名を引き受けた宰相

この解釈は、1553年の処刑と、その後の軍内・民衆・文学的反発を重視する。

ここでは、リュステムの悪評は、王朝的決定への責任を一人の宰相へ集約する記憶の仕組みとしても読める。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

リュステム・パシャの最大の課題は、

> どれだけ国庫を増やすか。

だけではなかったのかもしれない。

むしろ、

- 長期遠征、砦、艦隊、常備軍に必要な現金を、どの速度で中央へ接続できるか
- 現金化の負担を、徴税請負人、州、都市、農村のどこへどのように分散するか
- スレイマンへの近接性と王朝婚姻を、任官・外交・財政の実務へどう変換するか
- ハプスブルクとの休戦を、単なる和平ではなく、国境防衛と現金収益の調整としてどう使うか
- ムスタファをめぐる情報と不安を、王朝安全保障としてどう処理しようとしたか
- 巨大な私財とワクフを、将来の政治的不確実性に対する保護装置としてどこまで使えたか
- その制度運用が、軍事者・地方社会・宮廷にどのような不信を生んだか

が同時に問われていた可能性がある。

この見方では、リュステムは単なる「守銭奴」でも「改革の英雄」でもない。

> 拡張した帝国の現金・人事・軍事・都市・王朝を短期的に接続しようとした結果、その接続に伴う負担と反発を強く可視化された大宰相

として見える。

ただし、この構造的説明は、重税、任官の不正、処刑、王子継承をめぐる暴力、地方社会への圧力を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- リュステムの出生地、民族、宗教的出自、宮廷参入経路を確定しない。
- 「幸運の虱」逸話を確認済みの史実として扱わない。
- ミフリマーとの婚姻を、単なる陰謀または私的愛情だけで説明しない。
- イルティザームをリュステム一人が発明・全帝国化したと主張しない。
- 徴税請負を、常に効率的、または常に略奪的だったと一律に扱わない。
- 公的な任官納付、贈答、賄賂を自動的に同一視しない。
- ムスタファ処刑を、ヒュッレムとリュステムだけの陰謀と断定しない。
- スレイマンを、最終決定から切り離さない。
- リュステムの巨大な財産を、無条件に不正蓄財の証拠、または公共善の証拠として扱わない。
- 後世の「黒い心」「国家の柱」という像を、そのまま史実として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
