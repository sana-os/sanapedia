# メフメト1世

> **研究状態:** Provisional  
> **中心問題:** 1402年のアンカラの戦いから1413年のチャムルルまでに分断されたオスマン家の政治的接続を、メフメト1世は、都市、軍事者、土地・収益、地方支配者、外交、港、宗教施設を通じて、どこまで再び動かせる関係へ組み直したのか。  
>
> **注意:** このページは、メフメト1世を単なる「空位時代の勝者」や「国家を復元した一人の改革者」として扱わない。1413年の勝利は出発点であり、その後にも都市、軍事者、地方諸侯家、東ローマ、ヴェネツィア、セルビア、ワラキア、ティムール朝との関係を再接続する長い政治作業が必要だった。

# Human Overview

メフメト1世は、バヤジト1世の子であり、1402年のアンカラの戦い後に始まったオスマン空位時代を経て、1413年から1421年まで統治した人物である。

後世のオスマン史では、彼はしばしば「国家を再統一した君主」として描かれる。

この像には根拠がある。

1413年7月、ムーサ・チェレビを破った後、メフメトはエディルネで自らをオスマン家の唯一の統治者として示した。[^tdv-mehmed][^tdv-fetret]

しかし、1413年は「国家が元に戻った年」ではない。

アンカラ後の十一年間、オスマン家の諸皇子、アナトリア諸侯家、ルメリ軍事者、東ローマ帝国（後世の通称：ビザンツ帝国）、セルビア、ワラキア、ヴェネツィア、ジェノヴァ、ティムール側の政治的圧力は、それぞれ異なる地域で統治の条件を変えていた。

メフメトが引き継いだのは、単に空いた王座ではなかった。

彼が引き継いだのは、

- アマシヤ、トカト、ブルサ、エディルネなどの都市
- 軍事者の報酬と土地・収益
- 地方諸侯家の自立と服属のあいだの選択
- 港、海峡、船、商人、関税
- 城砦、道路、農村供給
- 東ローマ、セルビア、ワラキア、ヴェネツィアとの交渉
- 王朝成員の生存と請求
- 宗教者、法学者、書記、ワクフ
- 戦争と内戦の記憶

だった。

このページでは、メフメト1世を、

> 空位時代の後に、分断された統治接続を、完全ではなくとも再び反復可能な形へつなぎ直そうとした統治者

として扱う。

# Source Problem

## 「再統一者」という後世の像

メフメト1世は、後世の年代記や近代の概説では、「空位時代を終わらせた再統一者」として描かれる。

この表現は、1413年の政治的転換を示す上で便利である。

しかし、それだけでは不十分である。

「再統一」は、次の問いを隠しやすい。

- どの都市が、いつ、どの条件で新しい統治を受け入れたのか。
- どの軍事者が、報酬、土地、官職、安全のために支持を変えたのか。
- どの地方諸侯家が、服属、同盟、自立のどれを選んだのか。
- どの港と海峡が、交易、通行、軍事移動の条件を決めたのか。
- 東ローマやバルカンの支配者は、どのように諸皇子間の競争を外交的資源として使ったのか。

このページでは、「再統一」を完成した状態ではなく、

> 分断後の統治関係を再び繰り返し機能させる試み

として扱う。

## 勝者の年代記と地域社会の選択

主要なオスマン年代記は、最終的にメフメトの家系が統治を継続した時代に書かれた。

そのため、メフメトの勝利は「自然な回復」として見えやすい。

しかし、アンカラ後のアナトリアとルメリでは、地方諸侯家、軍事者、都市、商人、宗教者、外部勢力が、それぞれ異なる条件で行動していた。

彼らは単なる背景ではない。

彼らの支持・中立・離反・協力が、メフメトの政権が持続するかどうかを左右した。

# Historical Context

## Before: アマシヤの基盤と、分断された政治空間

メフメトは、1399年からアマシヤ・トカト・シヴァス・アンカラを含むルーム州と関わったとされる。

この地域は、単なる地方ではなかった。

そこには、

- トルクメン・タタール系の軍事者
- 都市の市場と書記
- 農村と土地・収益
- 旧地方支配者
- 道路と峠
- 黒海・中央アナトリアへの接続
- イスラーム法学者と宗教施設

が存在した。

アンカラ後、メフメトはこの地域を、単なる避難先ではなく、自らの王朝的請求を支える基盤として使った。

ただし、彼は無制限の支配者ではなかった。

地方支配者、トルクメン系軍事者、都市有力者は、それぞれが持つ土地・収益・安全・名誉の条件に応じて動いていた。

## During: 1413年は、再接続の始まり

1413年にムーサを破った後、メフメトはアナトリアとルメリを同一王朝のもとで再び結びつけようとした。

しかし、勝利は自動的に次を回復しない。

- 軍事者の忠誠
- 城砦の守備
- 土地・収益の配分
- 港と海峡の通行
- 都市市場の安全
- 地方諸侯家との関係
- 東ローマ・セルビア・ワラキアとの外交
- 王朝成員の請求を抑えること
- 宗教者・裁判・書記の制度的運用

メフメトの課題は、勝利を「日常の統治」へ翻訳することだった。

## After: 再統一のあとも、危機は残る

1414年以後の西アナトリア、1415年のカラマン、1416年の海戦と王朝的競争、シェイフ・ベドレッディンをめぐる問題、1419年のワラキア方面の軍事行動は、再統一後にも負荷が残っていたことを示す。

この時期の政治は、

> 一度壊れた政治体を、元の形に戻すこと

だけではなかった。

むしろ、

> 戦争と内戦のなかで変化した地域社会・軍事者・都市・外交関係を、新しい条件で再び接続すること

だった。

# Layer A — 生存・物質的安定性層

## 都市、軍事者、農村、港、海峡

メフメト1世が再接続しようとした統治は、抽象的な王権ではない。

それは次の物質的条件に依存していた。

- アマシヤ、トカト、ブルサ、エディルネの市場と食糧
- 農村からの穀物、水、家畜、税
- 軍事者の給与、土地・収益、戦利品、官職
- 城砦、道路、河川、渡河地点、使者
- ガリポリ、マルマラ、エーゲ海の港と船
- 東ローマ・ヴェネツィア・ジェノヴァとの通商と安全
- バルカンとアナトリアをまたぐ軍事・外交移動
- 都市の修復、宗教施設、ワクフ、建設資材、職人

1413年に単独統治者となった後、メフメトはこれらすべてを一度に完全に支配できたわけではない。

彼の政治は、各地域の条件に応じて、軍事、講和、任官、贈答、土地・収益の承認、寄進、外交を使い分ける必要があった。

## 1416年の海戦が示すもの

1416年のガリポリ沖海戦は、メフメト政権が「陸上で再統一した」だけでは十分でなかったことを示す。

海峡と港は、

- ルメリとアナトリアの移動
- 船と軍事輸送
- 商人と関税
- ヴェネツィアとの関係
- 東ローマの外交
- 島嶼・沿岸地域の安全

に関わっていた。

艦隊の敗北は、政権全体の崩壊を意味しない。

しかし、統治の再接続が陸上の軍事だけでは完結しなかったことを明確に示す。

# Layer B — 意味・認識層

## 「再統一」の意味は、集団ごとに異なる

メフメト1世の単独統治は、すべての人に同じ意味を持たなかった。

| 主体 | 「再接続」が意味した可能性 |
|---|---|
| 王朝と近臣 | 競合する請求の抑制、継承秩序、単独統治の可視化 |
| 軍事者 | 安定した報酬、土地・収益、官職、遠征機会、または中央からの監視強化 |
| 都市民 | 市場と交通の回復、税の予測可能性、軍事略奪の抑制、または新たな徴収負担 |
| 農村社会 | 戦争の減少、土地権利の確認、軍役や税負担の再編 |
| アナトリア諸侯家 | 講和と生存、地域的余地の縮小、旧領をめぐる再交渉 |
| 東ローマ帝国 | オスマン王朝の再強化を警戒しつつ、亡命者と海峡を外交資源にすること |
| セルビア・ワラキア | 直接的な軍事圧力と、複数のオスマン皇子を利用できた時期の終わり |
| ヴェネツィア | 通商上の安定、港の安全、オスマン海軍の再編への警戒 |
| 後世の王朝史 | 「秩序を回復した君主」という物語の形成 |

## 講和と譲歩をどう読むか

メフメトは、東ローマ、セルビア、ワラキア、カラマン、アナトリア諸侯家、ティムール側の圧力に対し、常に同じ政策を取ったわけではない。

ある局面では軍事行動を取り、別の局面では贈答、使節、講和、関係承認、抑制を選んだ。

これは「強い」か「弱い」かの二択だけで説明できない。

内戦後の統治では、

- 時間を得る
- 都市を守る
- 軍事者の報酬を維持する
- 敵対者を一度に増やさない
- 外部勢力が王朝内の競争者を使う余地を減らす

こと自体が、統治を再接続する条件だった可能性がある。

# Layer C — 制度・運用層

## 土地、収益、軍事者

メフメトの統治では、ティマール、土地権利、軍事報酬、地方の土地保有をめぐる関係が重要だった。

ただし、これを「メフメトが一人で制度を完成させた」とは言えない。

空位時代には、地方諸侯家、トルクメン・タタール系軍事者、都市有力者、農村社会が、異なる形で土地・収益・軍役に関わっていた。

1413年後の再接続には、

- 既存の権利をどこまで認めるか
- 誰に軍役と収益を与えるか
- どの地域を直接のサンジャクへ組み入れるか
- 誰を地方官・軍事指揮官として残すか
- どの家門と講和し、どの家門に軍事行動を取るか

という反復的な調整が必要だった。

## バヤジト・パシャと役割分担

バヤジト・パシャは、メフメトがアマシヤにいた時期から近臣として活動し、1413年には宰相格の地位とルメリ・ベイレルベイ職を担ったとされる。[^tdv-bayezid-pasha]

これは、メフメト政権が一人の君主だけで運用されたのではないことを示す。

統治には、

- 決定者としての君主
- 宰相
- ベイレルベイ
- カーディと書記
- 城砦司令官
- 地方軍事者
- 使節
- 港と市場の関係者
- ワクフ管理者

が関わった。

## 建築、ワクフ、都市的可視性

ブルサのイェシル複合施設は、メフメトの統治を象徴する建築として知られる。

ただし、建築は単なる「栄光の記念碑」ではない。

複合施設には、

- 礼拝
- 食事
- 教育
- 墓所
- 収益とワクフ
- 職人と建設資材
- 都市市場
- 王朝的記憶

が関わる。

このため、イェシル複合施設は、内戦後に「国家が復元された」ことの単純な証明ではない。

むしろ、

> 都市、寄進、労働、収益、王朝記憶を結びつけ、統治を日常空間に可視化しようとした試み

として読むことができる。

# Competing Interpretations

## Interpretation A: 空位時代を終えた再統一者

この解釈では、メフメト1世は1413年にムーサを破り、アナトリアとルメリのオスマン統治を再び一つの王朝のもとへ結びつけた人物として理解される。

この見方は、王朝的継続、軍事的安定、官職の再配置、建築後援を重視する。

## Interpretation B: 地域的妥協と再交渉を重ねた再接続者

この解釈では、メフメトの重要性は、単純な征服ではなく、地方諸侯家、軍事者、都市、東ローマ、セルビア、ワラキア、ヴェネツィアと、地域ごとに異なる関係を再交渉した点にある。

この見方では、講和、贈答、任官、土地権利の確認、軍事行動は、同じ統治作業の異なる手段となる。

## Interpretation C: 内戦後の国家能力を再構成したが、摩擦も強めた統治者

この解釈では、メフメト政権は、軍事、土地・収益、裁判、港、都市を再接続することで統治能力を高めた。

しかし、その再接続は、地方諸侯家、軍事者、農村社会、都市民にとって、税、軍役、土地権利、中央の監視をめぐる摩擦も生んだと考える。

## Interpretation D: 後世の王朝記憶が「回復者」像を完成させた

この解釈では、「空位時代の混乱」と「メフメトの回復」という対比は、後世の王朝史によって整えられたと考える。

この視点は、メフメトの政治的能力を否定しない。

それは、1413年以後も地域社会が直面した不安定さを、勝者の物語の外から見ようとするものである。

# What This Page Does Not Claim

- メフメト1世の出生年、母の出自、幼年期の詳細が完全に確定しているとは主張しない。
- 1413年の勝利が、アナトリア、ルメリ、バルカン全域をただちに均一なオスマン支配へ戻したと主張しない。

- シェイフ・ベドレッディンをめぐる1416年の問題を、単一の宗教的・社会的・政治的原因に還元しない。
- ブルサのイェシル複合施設を、単なる王朝的宣伝または自動的な社会的福利の証拠として扱わない。
- メフメト1世の「再統一」を、地域社会の自律性、土地権利、軍役、課税、戦争の負荷を消す言葉として扱わない。
- 構造的説明を、戦争、処罰、徴発、課税、不平等、支配の免罪として扱わない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
