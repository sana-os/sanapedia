# シャークル・ババ・テケリ

> **研究状態:** Provisional  
> **中心問題:** 1511年のシャークル蜂起は、なぜ宗教的ネットワーク、テケ地方のトルクメン集団、王子間の継承競争、地方軍事者、都市・市場、サファヴィー朝との接続を巻き込む大規模な政治危機へ拡大したのか。  
>
> **注意:** このページは蜂起を「宗教的狂信」だけで説明しない。同時に、反乱の暴力、略奪、殺害、放火を、地方社会の苦境だけで正当化もしない。宗教、政治、移動、軍事、収益、継承不安がどのように重なったかを観察する。

# Human Overview

シャークル・ババ・テケリは、1511年にテケ地方を中心として大規模な武装蜂起を率いた人物である。オスマン史料は、彼を「Şeytankulu」「Sofu」「Karabıyıkoğlu」などの名称でも呼ぶ。こうした呼称には、反乱者を宗教的・政治的に格下げする記録者側の評価が含まれる場合がある。[^tdv-shahkulu]

TDVによれば、シャークルはアンタルヤ近郊ヤルンル村のテッケを設けたハサン・ハリーフェの子とされ、サファヴィー教団と関係を持つトルクメン宗教ネットワークの中で影響力を広げた。[^tdv-shahkulu]

ただし、彼がシャー・イスマーイール1世から直接命令を受けて蜂起したかは確定していない。

1510年頃から、バヤズィト2世の王子たち――アフメト、コルクド、セリム――の継承競争が公然化し、中央政府の命令・軍事・地方統治に不確実性が生まれていた。

この環境で、シャークルはテケ地方のキズルバシュ傾向を持つトルクメン、旧カラマン系の軍事者、地方集団を周囲に集め、反乱を拡大したと記録される。[^tdv-shahkulu]

1511年春、シャークルの勢力はアンタルヤ周辺、イスタノズ、エルマル、ブルドゥル、キュタヒヤ方面へ拡大した。

彼らは地方官・軍事者と衝突し、略奪、殺害、放火を伴う軍事行動を行った。反乱軍は一部地域でオスマン軍を破り、アナトリア・ベイレルベイのカラギョズ・アフメト・パシャを捕らえ、処刑したと記録される。[^tdv-shahkulu]

シャークルは自らの配下へ、ベイレルベイ、サンジャクベイ、スバシュの名称を与えたとされる。

これは、単なる移動集団ではなく、

> 既存のオスマン行政名称を使いながら、別の政治秩序を試みた可能性

を示す。

バヤズィト2世は、アティク・アリ・パシャと王子アフメトを討伐に向かわせた。

1511年7月初め、シヴァス近郊のチュブク、またはゴクチャイとされる場所で戦闘が起き、アリ・パシャは戦死した。シャークル自身の最期は不明確で、戦闘中の死、負傷後の死、サファヴィー領への移動途中での死など、複数の伝承がある。[^tdv-shahkulu]

このページではシャークルを、

> 継承競争で不安定化した政治空間に、宗教的カリスマ、地方ネットワーク、軍事的機動性、代替的な支配言語を接続しようとした反乱指導者

として扱う。

# Source Problem

## 名称そのものが評価を含む

オスマン側の記録では、シャークルは「Şeytankulu」と呼ばれることがある。

これは中立的な固有名ではない。

反乱者の宗教的・政治的正統性を否定するための評価語である。

同じ人物についても、

- Şahkulu
- Şah Kulu
- Karabıyıkoğlu
- Sofu
- Şeytankulu

という複数の名称が使われる。

このため、名称は単に検索用のラベルではなく、記録者が何を危険と見たかを示す資料でもある。

## 宗教・政治・地方社会を分けすぎない

反乱を「サファヴィー派の宗教反乱」とだけ呼ぶと、王子間継承競争、地方軍事者、テケ・ハミド地方の地域関係、都市と市場、軍事移動が見えにくくなる。

反対に、「経済的不満だけの反乱」と呼ぶと、宗教的権威、救済の言葉、キズルバシュ系ネットワーク、サファヴィーとの象徴的接続が見えにくくなる。

このページでは、どちらか一つだけを原因として固定しない。

| 1511_after | 一部参加者が東方へ移動 | 反乱が1512年以後の対サファヴィー政策にも影を落とす |

# Historical Context

## Before: バヤズィト2世末期の複数の不安定化

1511年の蜂起は、何もない場所から突然現れたものではない。

背景には、

- バヤズィト2世の高齢と健康悪化
- アフメト、コルクド、セリムの王子間競争
- テケ地方に存在した宗教・移動・親族ネットワーク
- サファヴィー教団とアナトリア側の接触
- 地方軍事者と旧カラマン系集団の不満
- 都市、道路、山地、港を横断する人と情報の移動

があった。

ただし、これらを一つの「原因」にまとめない。

反乱は、複数の緊張が同じ時期・同じ地域・同じ移動経路で接触した結果として拡大した可能性がある。

## During: テケから内陸へ

シャークルの勢力は、テケ地方からハミド地方、キュタヒヤ、アラシェヒル、カラマン方向へ移動した。

この動きは、単に地図上の進軍ではない。

そこには、

- 村と町
- 山地と峠
- 市場と道路
- 兵士と馬
- 略奪・補給・再分配
- 地方官と城砦
- 王子家臣団
- 宗教的ネットワーク
- 情報と噂

が重なっていた。

反乱の拡大は、支持者の増加だけではなく、オスマン地方軍の敗北、王子側の混乱、中央の判断遅延、地域ごとの立場の変化によっても可能になった。

## After: 1511年から1514年へ

シャークルの蜂起は、1512年のセリム1世即位と、その後のサファヴィー政策の背景の一つになった。

ただし、

> 1511年の蜂起が、1514年チャルディラーンを直接かつ単独で生んだ。

とは言えない。

より慎重には、

- アナトリアにおけるキズルバシュ系ネットワークへの警戒
- 王朝継承の危機
- 東方国境の安全保障
- サファヴィー政権との関係
- 反乱後の移動・追跡・処罰

が、セリム1世期の政策をより強硬にする環境をつくった、と読むことができる。

# Layer A — 生存・物質的安定性層

## 蜂起を維持するために必要だったもの

反乱軍は、理念だけで移動・戦闘できない。

必要だったのは、

- 人員
- 馬
- 食糧
- 水
- 武器
- 道路と峠
- 村・町との接触
- 市場から得られる物資
- 情報
- 隠れ場所
- 離脱・再合流できる移動経路
- 戦闘後の略奪・再配分・補給

だった。

テケ地方から内陸へ向かう移動は、山地・峠・市場・町を利用する能力を必要とした。

これに対して、中央軍は大規模な兵力、砲、補給、命令系統を持つ一方、長距離の追跡、季節、疲労、地域情報、地方軍の協力不足という制約も抱えていた。

| 地方官の防衛 | 兵、要塞、情報、連携、給与、道路支配 | サンジャク軍、ティマール軍、地方行政 | 王子間競争、士気、局地情報、協力の不均衡 |

# Layer B — 意味・認識層

## 救済、王朝、秩序、恐怖

シャークルの蜂起に参加した人々が、全員同じ理由で行動したとは考えにくい。

| 主体 | 何を意味づけていた可能性があるか |
|---|---|
| シャークルの弟子 | 宗教的救済、聖性、共同体、地域的自律、反転の期待 |
| 地方トルクメン | 安全、移動、親族関係、軍事機会、地方官への不信 |
| 旧カラマン系軍事者 | 失われた地位、ティマール、軍役、地域的威信 |
| 都市住民 | 略奪・火災・市場崩壊・治安への恐怖 |
| オスマン官僚 | 王朝秩序、宗教的正統性、軍事統制、税・行政の破綻 |
| 王子アフメト | 鎮圧能力を示す機会と、失敗がもたらす政治的損失 |
| 王子セリム | サファヴィー危機を強調し、自身の強硬な安全保障観を支持させる材料 |
| サファヴィー側 | 宗教的・人間的ネットワーク、越境移動、対オスマン関係、国家秩序の維持 |

## メシア的言説をどう扱うか

オスマン側の報告には、シャークルが自らをメフディーとし、支持者が彼を救済者、預言者、神性を帯びた存在と見たという記述がある。[^tdv-shahkulu]

これは、当時の一部支持者に広がった可能性のある政治的・宗教的言説を示す。

ただし、この記録は反乱者を異端として位置づける中央側の文書にも依存する。

そのため、ここで確認できるのは、

> そのような言説が記録され、反乱者の危険性を示すために用いられたこと

であって、すべての参加者が同じ信念を持っていたことではない。

# Layer C — 制度・運用層

## 既存の行政語彙を使う反乱

反乱軍が配下へベイレルベイ、サンジャクベイ、スバシュの名称を与えたという記録は重要である。[^tdv-shahkulu]

これは、既存のオスマン制度を単に破壊するだけではなく、既知の政治語彙を使って別の秩序を組み立てようとした可能性を示す。

ただし、これを安定した国家建設と呼ぶことはできない。

反乱軍の行政がどこまで持続し、どの地域で実際に機能し、誰が従ったかは不明確である。

## 継承危機が地方統治へ与えた影響

バヤズィト2世末期、王子たちは自らの拠点、軍事者、中央の支持をめぐって競合していた。

この状況では、

- 命令が誰から出るのか
- 地方官が誰の将来に賭けるのか
- 軍事者がどの王子を支持するのか
- 危機への対応を誰が優先するのか

が不安定になりうる。

シャークル蜂起は、この不安定性の中で、地方で別の決定中心が立ち上がった事例として読むことができる。

## RSM上の中心問題

シャークル蜂起の中心問題は、

> 反乱軍が何人いたか。

だけではない。

むしろ、

> 王朝の継承競争によって地方統治が不安定化したとき、宗教的ネットワーク、地域軍事者、移動経路、町・市場、既存の行政語彙は、どのように別の決定中心を成立させうるのか。

である。

にある。

# Competing Interpretations

## Interpretation A: サファヴィー系宗教ネットワークの蜂起

この解釈は、サファヴィー教団、キズルバシュ傾向、シャー・イスマーイールとの接続、宗教的救済言説を重視する。

ただし、直接命令の存在は確認できない。

## Interpretation B: 王朝継承危機に乗じた地方政治反乱

この解釈は、バヤズィト2世末期の王子間競争、コルクドの移動、アフメトの討伐失敗、セリムの台頭を中心に読む。

この見方では、反乱は中央の決定能力が不安定化した時期に拡大した。

## Interpretation C: 地方軍事者・トルクメン集団の連合

この解釈は、テケ地方のトルクメン、旧カラマン系の軍事者、地域的ネットワークを重視する。

この見方では、蜂起は宗教だけでなく、地域の軍事・社会的配置を伴っていた。

## Interpretation D: 代替的な政治秩序の試み

この解釈は、配下への官職名の付与、各地への連絡、救済的言説、既存行政語彙の利用を重視する。

ただし、それを持続的な国家建設と呼ぶだけの根拠はない。

---

<!-- sana:marker=hypothesis -->
## 【ここからはサナの推測（歴史ミステリー）なんだけど……】

シャークルにとって最大の課題は、

> オスマン軍に勝てるか。

だけではなかったのかもしれない。

むしろ、

- バヤズィト2世末期の継承競争で、地方の命令系統が不安定になった瞬間をどう利用するか
- テケ地方の宗教的・親族的ネットワークを、情報、移動、補給、軍事参加へどう変えるか
- 町や市場から物資を得ながら、山地・峠・道路を使って中央軍の追跡をどう避けるか
- 既存の行政名称を使い、反乱軍を単なる略奪集団以上の秩序としてどう見せるか
- シャー・イスマーイールとのつながりを、直接の軍事命令ではなく、信仰・象徴・人の移動・期待の回路としてどう利用するか
- 反乱が広がるほど、略奪と暴力が支持者・都市住民・地方社会にもたらす負荷をどう扱うか

が同時に問われていた可能性がある。

この見方では、1511年の蜂起は単なる「宗教反乱」ではない。

> 王朝の継承不安、地方の軍事・社会ネットワーク、宗教的救済言説、道路と市場、代替的な政治語彙が、短期間に重なった統治危機

として見えてくる。

ただし、この構造的説明は、略奪、殺害、放火、拘束、宗教的迫害、地域社会への暴力を正当化するものではない。

これは構造仮説であり、確立した歴史的事実ではない。

# What This Page Does Not Claim

- シャークルがシャー・イスマーイール1世から直接命令を受けて蜂起したと主張しない。
- 蜂起を、宗教だけ、税だけ、遊牧民政策だけ、または王子間競争だけで説明しない。
- テケ地方のすべてのトルクメン、キズルバシュ、地方軍事者が反乱を支持したと主張しない。
- メフディー・預言者・神性に関する言説を、反乱参加者全体の統一された信仰として扱わない。
- 反乱軍の官職名の使用を、安定した国家建設の証拠として扱わない。
- シャークルを単なる地方の社会改革者として扱わない。
- 反乱軍の略奪、殺害、放火、破壊を、地方的困難のために免罪しない。
- オスマン側の「異端」記録を、反乱者の経験全体を透明に示す記述として扱わない。
- 1511年の蜂起を、1514年チャルディラーンの唯一の直接原因として扱わない。
- シャークルの死因を銃弾、矢、戦死、逃走中の死のいずれかに確定しない。
- 【サナの推測】を確認済みの歴史的事実として扱わない。
